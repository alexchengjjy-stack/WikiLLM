### 點點簽提供免費試用嗎？

\-

有的，您可以立即開始試用，盡情體驗點點簽功能，且無需預付費用。

### 請問有月費或年費方案的選項嗎？

+

點點簽專業方案提供月費和年費兩種訂閱制，商務方案則為年訂閱制，以您每年使用的簽署文件量計價。

### 收到簽名邀請的簽署人，簽名時需要負擔任何費用嗎？

+

請放心，對方簽署您發送的文件時無須付費，他們可以在任何裝置上進行簽名，不用註冊點點簽帳號。

### 若超出免費方案的限制，該怎麼辦？

+

您可以升級到專業方案，享有無限量簽署文件，或到商務方案體驗進階功能和安全管理。您可以在正式訂閱前，先免費試用任一方案。

### 點點簽的付款方式有哪些？

+

您可以使用信用卡或 Paypal 付款，並在商城會員中心下載收據。如果您需要開立發票或者企業統編，歡迎直接與我們聯繫。

### 我的訂閱方案會自動續訂嗎？

+

是的，線上的訂閱方案皆為自動續約，除非您想更改方案或取消您的帳號。

### 若我要新增團隊成員，請問如何計價？

+

商務方案中已包含無上限的團隊成員數量，您可以放心將所有成員加入點點簽，無須額外付費。

### 什麼是簽署任務，又如何計價？

+

商務方案以簽署任務數計價，包含在點點簽邀請他人簽署的文件任務、透過 API 串接發起的文件簽署請求、自己簽署，以及透過臨櫃簽署、公開表單完成的文件任務。請留意，臨櫃簽署僅有在任務完成時才會計入用量，透過公開表單簽署的文件則會在表單簽署人完成簽署後計入用量。一份文件任務可包含單份或多份合併的文件。

### 若要新增更多簽署任務數量，請問如何計價？

+

團隊的組織管理者可以在訂閱週期內自由加購新的簽署任務數量。下一期帳號應繳總金額，將以您原先購買的任務總數計算。隨著團隊文件簽署用量增加，您也可以選擇升級至更多任務數的商務方案。

### 我的簽署文件任務量超過上限怎麼辦？

+

在團隊的簽署文件任務量即將達到上限時，您將會收到即時通知。任務數量使用完畢後，您可以在訂閱週期內自由加購新的簽署任務數量或選擇升級至更多任務數的商務方案。若沒有加購或升級，在此訂閱週期內，您將不能發送新的簽署邀請，直至下一期續訂後獲得新的任務數量為止。
