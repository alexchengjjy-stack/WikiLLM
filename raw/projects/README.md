# raw/projects/ — 專案素材目錄

> 存放工作專案相關的**原始素材**，包含會議記錄、需求文件草稿、客戶往來信件摘要等。
> LLM Agent 會從此目錄攝入內容並建立或更新 `wiki/projects/` 下的專案頁。

## 命名規範

- 以專案代號 + 文件類型 + 日期命名：`ding-xin-meeting-20260513.md`
- 英文 kebab-case，避免中文檔名

## 適合放入的素材

- 重要會議記錄
- 客戶需求文件草稿
- 提案與報價相關備忘
- 技術規格討論記錄
- 里程碑決策記錄

## 不適合放入的素材

- 日常業務進展 → 放 `raw/BZSdata/SaaS/` 或 `raw/BZSdata/Projects/`（已有固定流程攝入）
- 純市場分析 → 放 `raw/BZSdata/eSign/`
