# raw/skills/ — 技能素材目錄

> 存放個人技能相關的**原始素材**，包含課程筆記、工具使用心得、學習重點截圖說明等。
> LLM Agent 會從此目錄攝入新技能並建立或更新 `wiki/skills/` 下的技能頁。

## 命名規範

- 以技能名稱 + 日期命名：`ai-prompting-notes-20260514.md`
- 英文 kebab-case，避免中文檔名
- 可直接存放學習心得的純文字記錄

## 適合放入的素材

- 課程重點筆記
- 工具操作流程記錄
- 學到的最佳實踐（Best Practices）
- 踩過的坑與解決方法
- 參考書籤與資源連結

## 不適合放入的素材

- 業務日報 → 放 `raw/BZSdata/SaaS/` 或 `raw/BZSdata/Projects/`
- AI 知識文章 → 放 `raw/AI_knowhow/`
- 市場資料 → 放 `raw/BZSdata/eSign/`
