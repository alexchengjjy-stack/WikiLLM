## 🗂️ 核心工作項分類架構 (Work Categorization)

本知識庫內之所有文件、專案進程與指令追蹤，嚴格區分為以下兩大項：

### 🟩 第一大項：BreezySign 好好簽現役業務 (Current Business)
1. **BreezySign Business**：整體營收與營運、跨部門協調。
2. **SaaS CSM & Projects**：SaaS 營運數字、Vertical 專案與 API 串接、SI 整合應用與 Project 收入。
3. **BreezySign Marketing**：官網 SEO/GEO 行銷、Blog 行銷推廣文案。
4. **BreezySign PM**：現行好好簽功能定義（如 AATL 憑證、10MB 大檔案防線、座標完簽 API 參數等）。
5. **Competitor & Compliance**：數發部能量登錄、SaaS 競品（點點簽、律果簽、FastSIGN 等）價格計費與轉單潮監測。

### 🟦 第二大項：BreezyBrain 好好腦下一代產品 (Next-Gen AI Product)
- 涵蓋 BreezyBrain 大腦從 **需求規格 (Spec) ➡️ 架構設計 ➡️ 程式開發 ➡️ 系統測試 ➡️ 行銷包裝/文案 ➡️ 大腦官網/推廣 ➡️ 客戶成功 ➡️ 後台系統 ➡️ 專案業務 ➡️ 整體營運 ➡️ 跨部門協調** 之全生命週期追蹤。
- *詳細指南與打標規範參閱*：[WikiLLM 工作項目分類與打標指南](playbooks/work-categorization-guideline.md)
