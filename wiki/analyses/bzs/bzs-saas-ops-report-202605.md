# BreezySign 好好簽 2026年5月營運月報

> **報告摘要**：本月報彙整 2026 年 5 月份 BreezySign（好好簽）之營運財務、SaaS 訂閱與退訂狀況、重點企業專案與 API 對接進度、競品市場動態（以點點簽漲價轉單為主），並提出後續執行與產品建議。5 月份受惠於專案款項入帳與點點簽轉單效應，總實收營收達到 **NT$ 385,602**，展現 SaaS 訂閱與系統整合（SI/API）雙引擎增長。同時，本月報增量勾稽了 SaaS 歷年四大維度演進、企業客戶畫像與 6 月最新競品情報普查，提供全局戰略指引。

## 四、BZS 訂單、認列與對帳機制

SaaS 的營運指標主要區分為「財務金流實收 (Recurring)」與「合約訂單額 (Booking)」兩種認列時間與口徑：
1. **財務會計實收認列 (Realized Revenue)**：
   - 以當月金流「實際扣款/電匯入帳」為基準。5 月總實收 **NT$ 385,602**（SaaS 實收 NT$ 104,480 + 專案實收 NT$ 281,122）。
   - 此數據為 5 月份最精準之財務 Production 基準。
2. **合約訂單認列 (Booking)**：
   - 以合約確認或開通生效日為基準。例如 **太平洋旅行社** 40 人企業年租約（NT$ 60,000），雖於 5/26 電匯入帳（認列於 5 月財務實收中），但合約生效日自 6/1 起算，業務面列入 6 月生效業績。
3. **對帳落差對齊**：
   - 後台金流與 CSM 登記數據達成 **NT$ 0 落差對齊**（新購 NT$ 73,200 + 舊客自動續訂 NT$ 10,880 = 實收 NT$ 84,080），對帳機制已步入規範化軌道。
4. **專案認列拆分**：
   - 本月專案與 API 實收 NT$ 281,122 佔總營收 72.9%，此類屬於一次性（One-time）的系統整合費用，應與 SaaS 經常性訂閱收入（Recurring Revenue）進行物理拆分核算，以精準反映 SaaS MRR/ARR 的健康度。

## 五、SaaS 歷年四大維度與成長漏斗分析 (2024-2026)

### 1. 歷年演進軌跡
* **獲客維度 (Acquisition)**：2024下半年註冊 2,126 次，2025年攀升至 3,738 次，2026前五個月累計達 1,620 次。Google Ads 5 月花費 NT$ 145,080。
* **營收維度 (Revenue)**：2024下半年營收 NT$ 95,400，2025年突破百萬達 NT$ 1,263,480，2026年前五個月累計達 NT$ 728,700。5月單月實收總營收創 NT$ 385,602 歷史新高（SaaS $104K + 專案 $281K）。
* **留存維度 (Retention)**：2026年透過 PipeDrive 記錄「發起任務家數」與「Line 操作詢問」，建立免費版活躍度預警，並利用未公開之「商務方案」作為降級防守 (Down-selling) 籌碼，預期可將流失率 (Churn Rate) 壓制在 5% 以內。
* **價值維度 (Value)**：2026上半年實收已完全收回獲客成本（Payback Period < 12 個月）。以年流失率 5% 估算，客戶終身價值 (LTV) 達 **NT$ 120,000**。

### 2. SaaS 核心指標名詞解釋與業界基準
為使營運數據評估具備一致性，以下定義好好簽 (BZS) 指標基準（匯率以 1 USD = 32 NTD 計算）：
- **CPA / CPL (每次獲取/名單成本)**：特指獲取單個註冊試用或高意圖諮詢 Leads 的廣告花費。
  - *台灣 B2B 基準*：NT$ 1,000 - 3,200 | *全球基準*：NT$ 2,500 - 6,400+
  - *好好簽實績*：**寬口徑** (含個人註冊) 為 **NT$ 465**，**窄口徑** (僅企業 Leads) 為 **NT$ 1,792**（落在台灣正常均值內，成效極佳）。
- **LTV : CAC (獲客效率比值)**：衡量獲客投資回報率的黃金指標（健康標準 > 3 倍）。
  - *好好簽實績*：**寬口徑**為 **258 倍**，**窄口徑** (B2B 決策基準) 為 **67 倍**（遠超業界標準，利潤空間極大）。

## 六、好好簽 (BZS) 企業客戶畫像分析 (Customer Personas)

好好簽的企業客群具備極強的「產業垂直性」與「需求異質性」，主要可歸納為以下六大畫像：
1. **醫療院所與生技保健 (HIS/PACS 系統整合、離線合規導向)**：
   - *代表客戶*：得勝者（盧森眼科）、衡星牙醫、膚適美仁愛診所。
   - *特徵*：強烈要求 API 座標完簽、PDF 轉 Dicom 回寫，及混合雲斷線時「地端離線暫存與 NTP 3天內校時上傳」的法規要求。通訊偏向使用 LINE 或簡訊 (SMS)。
2. **競品（點點簽）漲價流失之大量簽署轉單大戶 (高性價比、安全內控導向)**：
   - *代表客戶*：太平洋旅行社（40人年租），福安管理顧問（年簽2萬份），海沃管顧。
   - *特徵*：點點簽改以「按件計費」導致成本暴增，轉投我方「吃到飽年租方案」。高度要求 **UNIFY 範本權限集中控制**（子帳號禁止自建範本）與數發部能量登錄許可。
3. **不動產租售與代銷 (高敏證據、現場低阻力簽署導向)**：
   - *代表客戶*：第一建經、佶星廣告、二房東星鴻。
   - *特徵*：業務親訪看房需平板現場簽，並要求「邊簽名邊錄影」與 AATL 數位憑證以自證法律效力。
4. **大型教育與補教機構 (大批量、B2C 敏捷交付導向)**：
   - *代表客戶*：智基科技 (志光公職)。
   - *特徵*：年簽約量 3-5 萬份，決策鏈長，要求階梯式報價 (Tiered Pricing)，結合「公開表單簽」降低大批量發送行政成本。
5. **企業集團與數位行銷 (內部 BPM、KOL 簽約與私有雲/地端客群)**：
   - *代表客戶*：台北 101 地端 BPM 部署。
   - *特徵*：要求 WAF 規則放寬，Docker 地端部署，提供原始代碼安裝包，及 isHealth 異常監控。
6. **大檔案憑證限制之防禦邊界 (主動退守/非目標客群)**：
   - *代表客戶*：聖美麗健康管理。
   - *特徵*：健檢大圖 PDF 常超過 10MB，嵌入 AATL 憑證易失敗。我方主動婉拒年約，確立「單檔 10MB 憑證限制」的技術利潤防護線。

## 九、BreezySign 2026 行銷與營運策略全局綜合摘要 (H2 策略)

基於上述對帳、漏斗與競品普查，我們定調下半年四大戰略：
1. **建立財務與 CSM 數據月度對帳 SOP**：每月 5 號前完成勾稽，標記扣款失敗與電匯差，控制誤差在 5% 內。
2. **優化 PLG (Product-Led Growth) Onboarding 引導**：針對註冊後 50%~60% 從未簽署的 Cold Start 用戶，導入 3 分鐘引導動畫與範本，針對註冊 48 小時無動作 Leads 自動觸發 Email 並由 CSM 進行電訪關懷。
3. **擴大點點簽轉單定向行銷**：放開 Google Ads 預算天花板，以「年約吃到飽、不限件數」為核心，定向投放點點簽漲價受災行業（如旅行社、連鎖醫療、人資派遣），攔截潛在 Leads，再由 CSM 迅速 Onboarding 轉換。
4. **中台化與通路嵌入**：推動 API 與無程式碼元件，嵌入百加資通等 BPM 通路，加速 H2 規模化擴張。
