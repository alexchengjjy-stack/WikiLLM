# BreezySign 競爭戰鬥卡 (Battle Cards)

本戰鬥卡基於 2025H1 業務推廣日報中萃取的真實客戶反饋與抗性，為業務團隊提供**目標產業推廣腳本**與**低價競品防禦話術**。

## 🎯 第一部分：目標產業推廣腳本 (Industry Playbooks)

### 1. 旅遊業 (旅行社 / 旅遊服務)
* **代表客戶**：寶豐國際旅行社、林軒旅行社、三立旅遊等。
* **客戶痛點**：
  * 旅遊定型化契約簽署量大，傳統紙本或現場簽名造成人流壅塞與紙本歸檔困難。
  * 報名團客通常只需推派一人代表簽署，但聯絡方式多透過 Line 群組，而非 Email。
* **業務切入點 (Value Proposition)**：
  * **Line 傳簽**：強調「不用 Email，直接在 Line 群組丟連結就能簽」，極大幅度降低消費者的簽署阻力。
  * **遠距簽與自動歸檔**：主打「出團前就能遠端完成所有合約」，報到現場無需再處理繁瑣文書，提升客戶體驗。

### 2. 不動產與房屋租賃業
* **代表客戶**：龍邑不動產、宇浚地產、昀湟不動產等。
* **客戶痛點**：
  * 買賣/租賃合約版本極多（高達 20~30 種），且合約內容常需臨時修改。
  * 台灣不動產合約多為**「直式合約」**，市面上多數外商軟體對直式合約的欄位支援度不佳。
  * 內部需要搭配請款單等流程 (Power Form)。
* **業務切入點 (Value Proposition)**：
  * **完美支援直式合約**：主打本土化優勢，強調在手機與平板上，直式合約的簽署體驗與版面縮放遠勝外商。
  * **無縫 API 整合**：針對有建置 ERP 或內部管理系統的房仲品牌，強調「合約簽署狀態自動回寫 ERP」，業務無須重複登入多個系統。

## 🛡️ 第二部分：競品防禦話術 (Competitor Defense Scripts)

### 假想敵：律果簽 (LegalSign) 等低單價競品

**🛑 客戶常見抗性**：「我們在評估你們和律果簽，律果簽的價格好像比較便宜？」

**✅ 建議防禦話術 (Defense Strategy)**：

1. **將焦點從「價格」轉移到「合規證據力」**：
   * **話術**：「理解您有預算考量。不過電子簽章最核心的價值是發生糾紛時的『法律保護力』。好好簽每份文件都內建 **AATL 國際認證的數位憑證**，並且獨家支援『**聲明錄影**』。在台灣的法院判例中，能捕捉簽署人臉與動作的紀錄，才具備更強的『直接證據』效力。如果為了一點價差，在未來發生合約爭議時無法舉證，反而會造成企業更大的損失。」
2. **強調「通訊渠道」的轉換率**：
   * **話術**：「便宜的方案通常只支援 Email 發送。但在台灣，消費者幾乎不看 Email。好好簽深度整合了**簡訊發送**與 **Line 傳簽**。您可以直接在 Line 上把合約傳給客戶，客戶點開就能簽。這能幫您的業務團隊提升至少 30% 以上的合約回收速度，省下的時間成本絕對超過方案的價差。」
3. **擴充性與大企業信任度**：
   * **話術**：「好好簽是中華電信等大型標案廠商指定使用的合規工具，未來如果您的企業要接大廠的訂單，或者需要將簽名功能 API 串接到您們的內部系統，好好簽的微服務架構都能完美支援，不需要您未來再痛一次系統轉換的成本。」

### 假想敵：點點簽 (DottedSign)

**🛑 客戶常見抗性**：「我們目前是用點點簽，聽說點點簽是大品牌，為什麼要換成好好簽？」或是「點點簽通知我們要改以『每份合約計費』，好好簽的價格劃算嗎？」

**✅ 建議防禦話術 (Defense Strategy)**：

1. **直攻痛點：獨家支援 LINE 傳簽**：
   * **話術**：「大品牌的方案雖好，但在台灣的實務場景中，消費者根本不習慣看 Email。點點簽目前**不支援 LINE 傳簽**功能，這會導致您的業務在催簽時非常痛苦。好好簽提供深度整合的 LINE 傳簽，業務直接用 LINE 丟連結，客戶用手機點開就能在 10 秒內完成簽署。許多客戶（如卡稻農、不鑰科技）就是因為點點簽沒有 LINE 傳簽、催簽不易，才決定轉換到好好簽的。」
2. **戳中預算痛點：防範『以份計費』的隱形成本與重複計費陷阱**：
   * **話術**：「點點簽改採『按份計費』存在極大的預算黑洞。例如其 Powerform 公開連結規格，**只要簽署人重複點開連結但未完成簽名（如頁面跳出或消失），點點簽後台都會算作一筆合約並重複扣費**。高用量客戶（如直播主、旅遊團體）一天可能因此被多扣 4~5 份的冤枉錢，且客服無法解決。好好簽為企業提供吃到飽的固定方案，不會因為客戶點開未簽署就被重複計費，讓您能進行 100% 精準的費用控管。」
3. **穩定度與服務響應優勢**：
   * **話術**：「許多點點簽多年的老客戶反映，近期其系統經常出現卡頓，甚至點選合約需加載 1 小時的嚴重狀況，且客服要求客戶必須自行錄影自證才能排查。好好簽具備高可用性的 WAF 與 WLB 負載均衡備援，保障系統的高穩定度，並提供本土即時的技術客服，不讓系統問題耽誤您的業務成交時效。」
4. **API 串接 TCO (總持有成本) 對抗**：
   * **話術**：「雖然點點簽商務版開放了 API 且沒有額外收取 API 年費，但他後續是按每份合約高額計費。好好簽的 API 方案雖然有固定的年約費用，但因為**不限簽署件數與人數**，對於中大型企業的高頻發送需求而言，長期累積下來的總成本 (TCO) 其實遠低於點點簽。好好簽還提供一對一的專屬技術支援，協助您無縫對接。」
5. **無縫轉移支援與體驗**：
   * **話術**：「我們了解轉換平台會擔心歷史檔案與範本的移轉。好好簽提供企業方案體驗版，您可以先免費試用，我們的客服與業務團隊會協助您將點點簽的範本無縫轉移到好好簽，確保您的團隊在正式轉換前已經完全熟悉新流程，無縫接軌。」

### 假想敵：Microsoft Teams 內建簽核 / Power Automate 流程

**🛑 客戶常見抗性**：「我們公司已經在使用 Microsoft 365 和 Teams，裡面就可以做電子簽核了，為什麼還要花錢用好好簽？」

**✅ 建議防禦話術 (Defense Strategy)**：

* **話術**：「微軟 Teams 內建的簽核功能，實質上僅屬於**『同意/拒絕 (Approve/Reject)』的流程控制鈕**。在台灣的商業實務中，合約與請款通常需要**『手寫簽名』、『公司大小章』或具備法律證據力的軌跡記錄**。Teams 簽核不支援這些功能，也沒有 AATL (Adobe Approved Trust List) 國際認證憑證來防止文件被竄改。好好簽是完全符合台灣《電子簽章法》的合規工具，提供完整的數位憑證與審計軌跡，這才是真正具有法律效力保障的電子簽章服務。」
