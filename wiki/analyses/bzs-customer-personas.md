# 好好簽 (BZS) 企業客戶畫像分析 (Customer Personas)

> 本分析基於 2026 年度 BZSdata 超過 50 份的業務與專案日報萃取而成，旨在揭示台灣企業在真實採購電子簽章時的**客戶畫像 (Customer Personas)**。

從業務銷售情境歸納，好好簽的潛在客群具備極強的「產業垂直性」，主要可分為以下四大畫像：

### 1. 醫療院所與生技保健（高頻、終端病患面向）
- **代表客戶**：衡星牙醫診所、膚適美仁愛診所、仁和生物科技、泰瑞醫。
- **應用場景**：手術同意書、醫美諮詢單、醫療業務合作聲明書。
- **畫像特徵**：
  - 高度依賴既有的「醫療病歷系統」（如北極星），因此多數直接朝 API 深度整合評估。
  - **強烈的通訊習慣落差**：診所端表示終端病患「極少使用 Email」，高度要求透過 **LINE 或簡訊 (SMS)** 傳送簽署連結，以避免漏簽。
  - 對操作門檻零容忍：OTP 驗證若需要「Email + 手機」雙重驗證會被嫌棄過於複雜。

### 2. 不動產租售與代銷（高風險合約、安全證據導向）
- **代表客戶**：第一建築經理、NX 臺灣國際物流、**佶星廣告**（不動產代銷）。
- **應用場景**：房屋買賣契約、不動產委託書、跨國物流合約。
- **畫像特徵**：
  - **強烈的現場簽需求**：如佶星廣告，業務員親訪客戶時，需要平板或手機進行低阻力的現場電子化簽署，以取代紙本。
  - 對法律證據力要求極高，促使他們對「**邊簽名邊錄影**」與「**AATL 憑證**」有絕對需求。
  - 對檔案格式有特定執著：習慣於 Word 編輯流程，對「需轉 PDF 才能上傳」的斷層感到不便，具備線上 Word 預覽/編輯的潛在需求。

### 3. 大型教育與補教機構（大批量、跨部門協作）
- **代表客戶**：智基科技（志光公職補習班）。
- **應用場景**：學員報名表、補習班定型化契約。
- **畫像特徵**：
  - 單一客戶量級最大（年 3 萬 ~ 5 萬份）。
  - 採購決策鏈長，涉及總務、IT 與不同營運單位，導入通常需要數個月，並要求精確的階梯式報價（Tiered Pricing）。

### 4. 企業集團與數位行銷（內部 BPM、KOL 簽約）
- **代表客戶**：101（包含旗下 BPM 系統整合）、影響力數據顧問、鑫動力整合。
- **應用場景**：網紅經紀合約、NDA、企業內部簽核流程。
- **畫像特徵**：
  - 對於 API 整合要求極高，包含防火牆 (WAF) 規則放寬、資料庫欄位對應、以及私有雲 / Docker 的佈署與測試環境建置。

### 5. 工商顧問與聯誼諮商（高敏身分、身分核實）
- **代表客戶**：**盈泰澤丞**（單身聯誼/感情諮商）。
- **應用場景**：會員服務契約、免責聲明。
- **畫像特徵**：
  - **身分真偽極度敏感**：因涉及聯誼與諮商，必須確保簽署人為本人且意識清醒，對「**聲明錄影簽**」有硬性需求。
  - **管理成本導向**：原本使用紙本導致管理不易，且受制於點點簽漲價影響，高度看中「**吃到飽方案**」與「**操作直覺性**」。
