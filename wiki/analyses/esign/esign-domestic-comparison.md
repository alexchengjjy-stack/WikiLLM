## 2024 法規重大更新：電子簽章法修法

> [!IMPORTANT]
> 2024 年 5 月正式通過修法，確立了「電子簽章」與「實體簽章」具備同等法律效力。

### 核心變革：數位簽章的「推定」效力
修法後特別區分了**電子簽章**與**數位簽章**：
- **數位簽章**：指符合特定技術（如非對稱加密）且具備政府許可之憑證機構（CA）簽發憑證的電子簽章。
- **法律地位**：數位簽章在法律上被 **「推定為本人親自簽名或蓋章」**。這意味著在法庭上，除非對方能提出反證，否則法院將預設該簽名為本人意志。

### 對服務商的影響
- 所有本土服務商（點點簽、律果簽、好好簽、FastSIGN）均有提供對接 CA 憑證的方案，但只有在開啟該功能時，簽署結果才具備「推定效力」。
- 行政機關（除了司法程序外）在 3 年內必須全面接受電子簽章。

### 官方背書：數發部「服務能量登錄」
配合修法，數發部推出了[電子簽章解決方案服務能量登錄](../../sources/moda-esignature-energy-registration.md)機制，旨在盤點國內電子簽章技術服務能量。
- **點點簽、律果簽、好好簽與全景軟體(FastSIGN)均已成功取得該能量登錄許可**（證書效期兩年），形同取得進入 B2B 與 B2G（政府標案）市場的官方「白名單」門票，大幅提升服務公信力。

### 定價模式分析

```
若中小傳產 (無系統整合，年簽 500 份)：
點點簽商務：≈ NT$ 6,400-12,800（全團隊）
律果簽專業：NT$ 11,760 × 10 = NT$ 117,600/年
好好簽企業：NT$ 15,000/年 (10 人內)
FastSIGN 輕量：NT$ 25,000/年 (5 人內)

若為中大型企業需 API/ERP (如鼎新) 整合 (年簽 2000 份)：
好好簽 AATL 專案：NT$ 50,000 (含憑證與 API 首年) 
點點簽 API 專案：≈ NT$ 81,000（依客戶端訪談取得之競業估價）
FastSIGN Pro：採永久授權買斷制，初期建置費高但免後續訂閱。

→ 點點簽與好好簽在企業任務包制度與 API 報價上具極高價格競爭力。不過，點點簽近期全面轉向「以件計費」（如新商務版 500 份約 USD850）大幅調漲，且面臨系統卡頓問題，導致大量中小企業（如富友旅行社、麻吉行得通、聖美麗健康顧問）流失，這波出走潮甚至讓尚未約滿的客戶提早尋找替代方案。但也有企業（如言果學習）為了規避份數限制，選擇以多人共用單一「專業版（個人版，USD96/年）」帳號的方式續留，因為該方案合約份數無上限。
→ 律果簽在單一人數少、需要極度合規的全生命週期管理情境下有價值。但在處理極大合約量（如年簽 3.5 萬份）時遭遇嚴重效能瓶頸，目前以私有雲落地方案作為防禦策略。
→ FastSIGN 提供罕見的買斷制，適合預算編列為 CAPEX 的政府機關或傳統大型企業。

根據 BZS 業務觀察，市場正經歷一波轉換潮：
- **外商退潮**：Docusign 面臨本土廠商的「免費試用戰術」挑戰；Dropboxsign 則因每年穩定調漲 15% 價格且無法配合修改操作體驗而流失客戶。
- **本土系統效能考驗**：點點簽與律果簽在客戶累積與合約量大增後，雙雙面臨系統卡頓（如合約載入需數分鐘至 1 小時）的技術債挑戰，這成為其他廠商切入的突破口。
```

## 差異化特色總結

### 🏆 點點簽的核心優勢
1. **成本效益最高**（人多的團隊，按任務數計價）
2. **第三方整合最豐富**（Google / Zapier / Teams）
3. **API 最易獲取**（商務方案即可，且不另收費）
4. **國際化**（USD 計價，Powered by KDAN）

### 🏆 律果簽的核心優勢
1. **唯一內建完整 CLM**（合約全生命週期管理）
2. **法律服務導向**（企業法顧、法律合規性最強調）
3. **方案分級最細**（5 級，升級路徑最平滑）
4. **紙本合約數位化**（掃描歸檔 + 全文檢索）

### 🏆 好好簽的核心優勢
1. **聲明錄影**（唯一，增強法律證據力）
2. **蒙恬簽名板**（硬體整合，適合實體場所）
3. **Line 傳送**（台灣在地化最深）
4. **印章儲存**（符合華人商業文化）

### 🏆 FastSIGN 的核心優勢
1. **買斷制授權**（Pro 方案提供罕見的永久授權，適合政府與特定大企業）
2. **純血資安大廠**（母公司全景軟體具備深厚的政府憑證中心整合經驗）
3. **AD 與 OTP 無縫整合**（專注於企業內部 IT 安全控管）
