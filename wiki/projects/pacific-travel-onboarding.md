# 太平洋旅行社 Onboarding

> 本專案用於引導太平洋旅行社股份有限公司順利從點點簽遷移至好好簽，並完成 40 人企業正式版方案的啟用、UNIFY 範本權限制定與業務登入流程宣導。該公司已於 2026-05-26 支付年費 NT$60,000，合約於 2026-06-01 正式生效。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶窗口** | 太平洋旅行社承辦人 |
| **訂閱方案** | 企業版 40 人年費合約 (NT$60,000) |
| **起訖時間** | 2026-06-01 ~ 2027-07-01 (6/1 前完成準備，6/1 正式啟用) |
| **特殊設定** | 客服設定 `UNIFY` 範本共享模式 (各業務帳號無法自建範本，全由主帳號分發) |

## 目前狀態（截至 2026-06-05）

### ✅ 已完成
- [x] 解答客戶關於 Line 傳簽產生連結與簡訊點數計費方式的諮詢。 (5/20)
- [x] 提供電匯付款資訊，客戶於 5/26 完成匯款。 (5/26)
- [x] 客服完成後台設定變更，將客戶範本功能切換為不可逆之 `UNIFY` 共享範本模式（限制一般子帳號自建，僅限主控帳號分發）。 (5/21)
- [x] 完成 40 個業務帳號的匯入準備，測試承辦人已驗證可直接以 Google 帳號授權登入使用。 (5/22)
- [x] 將企業體驗版展延至 5/31，以便 6/1 正式版銜接。 (5/21)
- [x] 2026-06-01 正式版啟用：開通正式企業方案 40 人年費權限，完成後台 UNIFY 權限配置，且 40 個子帳號皆能順利登入使用。 (2026-06-01)
- [x] 協助主管理帳號建立並發行第一批消費者「旅遊定型化契約」範本（已設定 UNIFY 共享完畢）。 (5/21)
- [x] 提供客服教育訓練簡報與視訊錄製素材，協助 30 位業務人員快速熟悉 Line 傳簽及現場簽署流程。 (5/22)

### 🔄 進行中
- [ ] 監控首月任務發起數與完簽率，追蹤系統效能與穩定度反饋。
