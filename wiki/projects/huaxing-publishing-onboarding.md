# 華杏出版 Onboarding 專案

> 本專案為好好簽（BZS）針對華杏出版有限公司（60 人，教科書出版老牌）之 Onboarding、操作輔導與付費訂閱轉化專案。此專案代表好好簽依據數發部能量登錄（EEAT 公信力）吸引傳統合規性行業，並平滑轉化個人專業版（及後續企業版升級）之 PLG 與 SLG 混合成交典型。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶名稱** | 華杏出版股份有限公司 (書籍出版業) |
| **發起場景** | 作者雙方合作合約（B2C，單一作者為主），用量約 5~10 份/月 |
| **當前方案** | 個人專業版（教學任務體驗升級版，免費試用 3 個月，至 2026-08-26） |
| **目標方案** | 3 個月到期後付費訂閱專業版 (NT$3,000/年)，未來轉化為企業方案 |
| **主要同仁** | 3 位常操作同仁（共用同一個個人帳號操作） |
| **窗口 / 負責人** | 好好簽客戶成功與銷售小組 (Sales & CSM) |

## 目前狀態（截至 2026-05-27）

### ✅ 已完成
- [x] **需求捕獲**：5/18 安排簡報展示。承辦人因寄送紙本合約遺失與延遲而主動在網路搜尋符合數發部能量登錄廠商找到好好簽。
- [x] **線上演示 (Demo)**：5/26 下午 2:00 完成 Google Meet 線上簡報與操作演示，客戶三位同事與主管全程參與，反饋良好。
- [x] **升級體驗版**：5/26 會後順利開通，將客戶的免費版帳號升級為「專業方案體驗版」，引導承辦人完成新手教學任務，正式開啟 3 個月的免費試用期。

### 🔄 進行中
- [ ] **試用期操作監控**：CSM 定期觀測華杏出版之簽署發起數量與完簽狀況，提供主動排障支援。
- [ ] **共用帳號警示與大戶防線建立**：產品團隊正積極規格化「個人方案 100 份/月限制與超額 NT$30/份加購」機制。需在試用期內密切觀測其 3 人共用帳號之簽署量，以利體驗期滿後引導其合規訂閱或升級為 5 人企業版 (NT$15,000/年)。

### 📅 即將執行
- [ ] **試用 30 天關懷電訪 (6月下旬)**：CS 團隊去電承辦人，詢問作者端手寫簽署之流暢度，與 LINE 傳簽之測試回饋，鞏固產品 Aha Moment。
- [ ] **8/26 體驗到期續約跟進**：引導正式電匯或線上刷卡，完成 NT$3,000/年之正式訂閱。
