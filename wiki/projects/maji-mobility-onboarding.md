# 麻吉行得通 Onboarding

> 本專案用於追蹤麻吉行得通股份有限公司由點點簽（DottedSign）轉換至好好簽之方案評估與 Onboarding 引導。該客戶之點點簽合約將於 2026-08-03 到期，目前好好簽功能測試已完成，正等待內部主管做最終更換方案決策。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶窗口** | 行政部承辦人 |
| **當前用量** | 500~600 份/年 |
| **點點簽到期** | 2026-08-03 |
| **目標方案** | 企業方案（基本 5 人版）|

## 目前狀態（截至 2026-06-01）

### ✅ 已完成
- [x] 提供好好簽企業方案（體驗版）進行跨部門測試，試用至 5/21，承辦人反饋遠距簽、Line 傳簽功能操作順暢。 (5/20)
- [x] 解答承辦人關於僅有 4 位跨部門承辦人共用，是否能給予優惠的諮詢（說明企業方案以 5 人起算為最低限度）。 (5/20)
- [x] 5/29 成功電話聯繫上承辦人，確認其評估進度，獲知目前正等待主管決定是否更換方案。 (5/29)

### 🔄 進行中
- [ ] 7 月初預定跟進：因其點點簽 8/3 到期，承辦人表示主管若核定轉換，預定 7 月初開始處理。我方定於 7 月初重啟跟進。
- [ ] 提供主管決策所需的比較資料或簡報支援，以排除轉換疑慮。

### 📅 即將執行
- [ ] 配合客戶 7 月轉換時程，若有需要，協助開通多個體驗版子帳號或展延試用時間。
- [ ] 若通過主管決策，協助處理電匯報價單並引導 4 個部門（行政、人資、業務、財務）完成 Onboarding 流程。
