# 百加資通 BPM 通路合作

> **核心商業邏輯**：由於好好簽 (BreezySign) 現階段尚無內建的 BPM (企業流程管理) 功能，因此當客戶需要複雜的內部表單簽核流程時，我們會將商機轉介給合作夥伴 **101plus (百加資通)**（BPM 與 EIP 系統商）。101plus 作為 BZS 的 SI（系統整合商），將好好簽 API 嵌入其旗下產品中，由我們向其收取系統整合顧問費或成案分潤。

> **注意**：此處的「101plus」指合作夥伴公司名稱（百加資通），其核心產品為 **101Form (BPM)** 與 **101EIP (企業情報門戶)**，而非獨立客戶。

## 合作架構

| 項目 | 內容 |
|------|------|
| **合作夥伴** | **101plus (百加資通股份有限公司)** |
| **合作模式** | SI 引薦 → BZS 電子簽章 API 整合 → 101plus 取得轉介分潤（30%）|
| **目標市場** | 大型企業、製造業、醫療院所、政府機關（有嚴格資安與 EIP 需求）|
| **產品整合** | 好好簽 API + 101plus 旗下產品 (**101Form BPM** / **101EIP**) + 雲端人資管理系統 |

## 引薦客戶案例

| 客戶 | 產業 | 需求 | 狀態 |
|------|------|------|------|
| **百加-巨虹電子（青熙醫美）** | 醫美 | 電子簽章整合，顧問費與分潤結算 | ✅ 已請款：系統費 $127,418；BZS 分潤 30% = $38,225（含稅）|
| **101plus引薦-精鈺金屬工業** | 汽車零件製造 | BPM 人資與請假流程（員工 90 人）| 🔄 評估中：確認是否有 HR 系統（可 API 串接 **101Form**；或加購 101plus 雲端人資管理）|

## 分潤模式

- BZS 收取全額服務費後，撥付引薦合作夥伴（百加）**30%** 轉介分潤
- 範例：巨虹電子系統費 $127,418 × 30% = $38,225（含稅）撥給百加

## 市場策略意義

- **101plus (百加資通)** 旗下 **101Form** 與 **101EIP** 客群以**大型企業、製造業、醫療機構**為主，是 BZS 較難直接觸及的客戶群
- 透過 BPM 系統（101Form）「嵌入式整合」，電子簽章成為業務流程的必要元件（不易被替換）
- 相比 SaaS 直銷，SI 合作的客單價更高、客戶黏著度更強
