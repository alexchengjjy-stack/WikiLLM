# 聯合線上 API 對接與公開表單專案

> 聯合線上股份有限公司（udn新聞）導入好好簽（BZS）電子簽章 API，解決其外部公開表單尚未支援 AATL 數位憑證的缺口，並提供完整的線上簽署防偽機制。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶名稱** | 聯合線上股份有限公司 (udn / 聯合報系) |
| **技術方案** | 好好簽 (BZS) API 串接、公開表單 AATL 支援 |
| **預估規模** | 專案合約 NT$30,000，包含 1,500 份 AATL 憑證 |
| **核心需求** | 「公開表單」API 化與 AATL 支援，防偽簽署流程測試 |

## 目前狀態（截至 2026-06-02）

### ✅ 已完成
- [x] 初步溝通：聯合線上指出外部公開表單未支援 AATL 的缺口 (2026-04)
- [x] 專案合約與價格確認：專案款項調降為 NT$30,000，包含 1,500 份 AATL 憑證 (2026-05-20)
- [x] API 實作對接完成：BZS 技術團隊協助完成公開表單 API 的開發與對接 (2026-05-29)

### 🔄 進行中
- [ ] **流程測試**：聯合線上業務單位正在進行業務流程與防偽簽署流程測試。
- [ ] **防偽安全評估**：針對高意圖簽署場景的安全機制與 AATL 數位印章防偽特性進行驗證。

### 📅 即將執行
- [ ] 正式驗收並部署上線。
- [ ] 監控公開表單在正式環境的 API 調用量與 AATL 憑證封裝效能。
