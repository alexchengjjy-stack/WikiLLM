# 國泰神坊小樹購電簽導入評估專案

> 本專案為**大戶 Lead 評估型專案**：國泰集團旗下神坊資訊 (Symphox) 評估為其電子商務平台「小樹購」導入好好簽 (BZS) 電子簽章服務。主要用於當用戶於平台開通特定功能時，在線上完成合約條款的同意與簽署流程，以符合《電子簽章法》之自證力效力。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶名稱** | 神坊資訊股份有限公司 (Symphox) / 小樹購 |
| **預估用量** | 每年約 2,000 份簽署任務 |
| **對接窗口** | Kelly (BZS 產品顧問) |
| **目前階段** | 初步評估、價格協商、金融合規實績提供 |

## 目前狀態（截至 2026-05-28）

### ✅ 已完成
- [x] 提供 BZS 企業/API 牌價參考（年費 15 萬、AATL $30/份、雲端 $80/份、簡訊 $2/則） (5/28)
- [x] 釐清應用場景：小樹購用戶加入特定功能時的合約條款簽署 (5/28)

### 🔄 進行中
- [ ] **法務審核**：神坊資訊法務部進行細部合規性評估與條款審查
- [ ] **商議年費價格**：客戶反饋年費 15 萬偏高，Kelly 與團隊正研擬針對 2,000 份年用量的客製化報價方案
- [ ] **金融實績提供**：由於小樹購背後多為資安敏感金融客戶，BZS 團隊需整理並提供金融業合作實績以說服其資安與風控部門

### 📅 即將執行
- [ ] 提交 BZS 金融業合作實績案例與資安防護白皮書
- [ ] 提出修正後的客製化報價單

## 專案挑戰與對策
1. **金融業資安門檻**：國泰集團為金融巨頭，對資安要求極為嚴格。好好簽應強調**數發部電子簽章解決方案服務能量登錄**與 AATL 憑證合規防偽特性，並準備專屬資安與隱私防護文件。
2. **年費價格協商**：年費 15 萬對 2,000 份規模的專案而言，客戶反饋較高。可研議將部分 AATL 額度免費內含於年費，或提供首年導入優惠以加速簽約。
