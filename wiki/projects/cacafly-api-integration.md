# 聖洋科技 API 串接專案 (cacafly)

> 本專案為好好簽（BZS）與大型數位行銷集團聖洋科技 (cacafly) 的 API 系統對接專案。該客戶年用量預估達 **8,000 ~ 10,000 份**。專案的核心技術與產品規格，在於解決其集團旗下多家不同子公司進行「合約發起時的 Multi-branding 品牌自訂與 Logo 隔離識別」痛點。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶名稱** | 聖洋科技股份有限公司 (cacafly) |
| **預估用量** | 一年約 **8,000 ~ 10,000 份** |
| **技術方案** | 好好簽標準 API 串接 + 範本動態帶出 (Template Fill API) |
| **核心規格** | 集團子公司自訂合約帶出名稱、Logo 與品牌識別 (Multi-branding) |
| **窗口 / 負責人** | **Kelly** (好好簽產品顧問，大戶專人對接) |

## 風險與注意事項
- ⚠️ **毛利稀釋風險**：客戶用量極大，不可直接適用個人專業版或常規 NT$15,000 企業方案。必須以 Kelly 制定之商務大額方案進行 SLG 包抄，守住 AATL 變動成本。
- ⚠️ **Multi-branding 產品演進**：目前的 Unify 範本管理主要由主帳號全權共享。為了服務此大戶，產品 PM 需將「Unify 範本共用細分權限重構」與「動態帶出子公司 Logo」之規格排入 SaaS Backlog。
