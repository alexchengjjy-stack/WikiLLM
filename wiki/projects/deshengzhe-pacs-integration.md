# 得勝者 PACS 醫療影像系統電簽整合專案

> 本專案為**醫療系統整合與業務推廣專案**：得勝者旗下診所導入好好簽作為無紙化簽章工具；同時，得勝者與商之器（EBM Technologies）洽談其 PACS 後台 AI 醫療影像平台 mAIn 之後台 AI 引擎電簽 API 整合。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **主導單位** | 得勝者 |
| **整合夥伴** | 商之器 (EBM Technologies) |
| **技術方案** | 好好簽 (BZS) API 串接、AATL 數位憑證 |
| **主要場景** | 眼科診所合約/病歷無紙化簽署、後台醫療影像報告 AI 簽核 |

## 目前狀態（截至 2026-06-08）

### ✅ 已完成
- [x] 確立盧森眼科與東港盧森時程：預定於 6 月進行測試， 7 月正式啟用上線。 (5/28)
- [x] 確認診所簽約金額：合計 NT$50,000 (含稅)，包含每家 NT$25,000 的系統授權與 1,500 份 AATL 憑證。 (5/28)
- [x] 與南港商之器初步洽談：了解其 mAIn 醫療影像 AI 平台串接後台 PACS 機制 (Pass-Through 影像運算機制)。 (5/28)
- [x] 6/1 早上會議：深入了解得勝者今年整體的規劃與商之器整合進展。 (6/01)
- [x] 技術追蹤：釐清中華電信時間戳記在「離線暫存」情境下可接受之誤差與最長可離線天數。確認醫療法規中電子病歷支援「可離線但需在 3 天內校正」規範。規劃在診所地端設置 BZS 輕量中繼程式以應對短期斷線，待與中華確認確切離線交換天數。 (6/05)

### 🔄 進行中
- [ ] 提供商之器工程窗口 BZS API 文件，確認其 PACS 後台 AI 拋出影像報告之電簽串接細節（後續會使用 PDF 發起任務 + 簽名座標整合模式）。
- [ ] 技術追蹤：研擬支援「簽名座標」的 BZS API 參數規格設計並回覆整合商。
- [ ] 業務追蹤：推出低門檻（50-100 份）、高單價、無使用期限的「體驗包」（價格約 NT$1,000 - 2,000），培養習慣紙本醫師的電簽使用習慣。
- [ ] 業務追蹤：結合得勝者、方鼎、PP 與商之器，打包推出「診所 HIS＋電子病歷＋電子簽名＋影像管理」聯合銷售方案，並以「盧森眼科」為首波示範站（預計 6-8 月上線）。

### 📅 即將執行
- [ ] 於 Staging 環境開通得勝者及商之器測試帳號，進行 mAIn 影像報告自動化發起與簽署測試。
- [ ] 協助盧森眼科與東港盧森建立診所電子病歷範本與 Onboarding 引導。
- [ ] 規劃 8 月聯銷方案穩定後，以 Seminar 形式向眼科及醫美市場（如郁仁診所、善珉眼科）進行推廣。
