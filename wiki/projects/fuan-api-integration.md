# 福安健康與職安 API 專案

> 本專案為**大戶 API 導入與轉單專案**：福安管理顧問企業社每年有高達 20,000 份簽署合約的需求。因點點簽（DottedSign）於 2026 年中改以份數計費導致其續約報價大增，促使客戶轉向好好簽（BZS）進行技術對接與方案導入。

## 專案概覽

| 項目 | 內容 |
|------|------|
| **客戶名稱** | 福安管理顧問企業社 |
| **業務窗口** | Kelly / Jack |
| **技術方案** | 好好簽 (BZS) API 串接、8,000 份 AATL 憑證 |
| **專案報價** | NT$120,000（包含 8,000 份 AATL 憑證） |
| **核心場景** | 勞工健康與職安服務文件簽署。每份文件約需 8-9 位人員完簽。 |

## 目前狀態（截至 2026-06-02）

### ✅ 已完成
- [x] 客戶主動接觸：福安點點簽合約於 6/30 到期，因點點簽漲價尋求好好簽替代方案。 (2026-05-19)
- [x] 提供 ISO27001 資安認證與數發部能量登錄佐證文件。 (2026-05-29)
- [x] 技術方案評估：確認職安文件需 8-9 人多方簽署。Hank 評估兩種技術做法：
  - *做法1*：由職護填寫後發送 PDF 至 BZS 進行簽署。
  - *做法2*：於瑞飛系統完簽後將軌跡與檔案傳送至 BZS 進行 AATL 憑證封裝。
- [x] 專案報價與協商：針對 8,000 份 AATL 提供 NT$120,000 的 API 客製化專案報價。

### 🔄 進行中
- [ ] **合約與專案簽約**：進行合約細節審查與專案簽約作業。
- [ ] **教育訓練規劃**：準備 Google Meet 線上教育訓練投影片，預計錄製訓練影片供福安內部同事與職護參考。

### 📅 即將執行
- [ ] 正式完成合約簽署。
- [ ] 於 Staging 環境開通測試帳號， Hank 協助其開發團隊或瑞飛系統對接。
- [ ] 驗證 8-9 位多方傳簽與 AATL 數位憑證封裝效能。
