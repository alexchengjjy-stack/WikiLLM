# 企業試用版跟進 Checklist

> **試用期是轉換率的決勝點。任務數 > 10 的客戶，付費轉換率顯著高於任務數 < 3 的客戶。**

## ✅ 完成定義

- [ ] 客戶體驗版到期前已主動聯繫
- [ ] 已提供報價單（如客戶有意願）
- [ ] 已決定後續狀態（付費 / 延長試用 / 結案）
- [ ] 日報已記錄最新進展

---

## 何時使用

每次開通企業版體驗版後，依此 Checklist 執行跟進

---

## 開通當天（Day 0）

- [ ] 升級帳號為企業方案體驗版
- [ ] 確認試用到期日（記錄到日報 / 追蹤表）
- [ ] 發送歡迎 Email，附上：
  - 快速入門教學連結
  - 常見 FAQ
  - 聯絡方式（Line / Email）

---

## 第 3 天（Day 3）

- [ ] 登入後台，確認任務數
  - 任務數 = 0 → **主動聯繫**，詢問是否有使用問題
  - 任務數 ≥ 1 → 觀察，發一則鼓勵訊息

---

## 第 7 天（Day 7）

- [ ] 再次確認任務數增長趨勢
- [ ] 主動發訊詢問使用狀況：
  ```
  您好，試用大約一週了，請問功能使用上有遇到任何問題嗎？
  如果有任何操作疑問，歡迎直接詢問！
  ```
- [ ] 視需要提供進階功能介紹（範本設定 / 批次簽 / AATL 說明）

---

## 到期前 3 天（Day -3）

- [ ] 確認客戶意願（電話或 Email 聯繫）
- [ ] 如有購買意願：
  - [ ] 提供對應方案的正式報價單
  - [ ] 確認付款方式（信用卡 / 匯款）
  - [ ] 如選擇匯款，提供帳戶資訊與電子發票說明
- [ ] 如需延長試用：
  - [ ] 確認延長理由（尚在內部審核 / 需更多測試）
  - [ ] 最長延長至 30 天（超過需 Alex 確認）

---

## 到期後

- [ ] 若已付費：確認訂閱啟動，記錄成交日報
- [ ] 若未付費：
  - [ ] 詢問是否有決策障礙（預算 / 功能缺口 / 內部流程）
  - [ ] 如 3 個月後仍無回應 → 標記為「觀望」，降低跟進頻率

---

## 常見狀況處理

| 狀況 | 處理方式 |
|------|----------|
| 公司沒有信用卡，需匯款 | 提供報價單 + 帳戶資訊，說明匯款後開立電子發票 |
| 需要公司流程審核（財團法人 / 大型企業）| 提早 7 天開始跟進，協助準備採購文件 |
| 承辦人說「主管/執事/董事長還沒看」| 提供正式報價單格式，方便層報 |
| 試用期間遇到 Bug | 立即通報技術，若影響評估，考慮主動延長試用 |
| 客戶不回覆 | 試用到期前 1 天發最後一封簡短 Email，之後停止主動聯繫 |

---

## 驗證完成

- 到期前已聯繫客戶 ✓
- 報價單已提供（如適用）✓
- 日報已記錄最終狀態 ✓

---

## 高轉換率信號 ⚡

以下情況出現時，代表轉換機率很高，應立即跟進：

- 任務數突然大幅增加（如 1 週內 +50）
- 承辦人主動詢問「如何購買」、「可以匯款嗎」
- 承辦人說「要跑公司流程」（代表已內部核准）
- 有多人帳號需求（代表已開始推廣給同事）
