# 新潛客資格確認 SOP

> **沒人會讀 50 頁文件。讓它可掃描、可執行，而且不可能被誤解。**

## ✅ 完成定義（先確認這些才算做完）

- [ ] 確認客戶行業別與員工人數
- [ ] 確認主要簽署需求（文件類型、月份數、簽署對象）
- [ ] 確認來源管道（搜尋 / 廣告 / 推薦 / 能量登錄）
- [ ] 決定下一步動作（推薦方案 / 開體驗版 / 轉 Kelly / 僅留 mail）
- [ ] 在日報中記錄完整資訊

---

## 何時使用

- 每天處理 Inbound 新進件時
- Line 官方帳號有新詢問時
- 客戶主動留電話要求聯繫時

---

## 前提條件

- 已有客戶基本資料（公司名稱、聯絡方式）
- 可登入好好簽後台查看試用帳號狀態

---

## 流程

### 步驟 1：取得基本資料（2 分鐘）

確認以下欄位（來自進件表單或電話詢問）：

| 欄位 | 說明 | 備註 |
|------|------|------|
| 行業別 | 醫療 / 不動產 / 製造業 / 教育 / ... | 影響方案推薦 |
| 員工人數 | 決定版本（專業/企業/Enterprise）| |
| 資本額 | 判斷付費能力 | |
| 來源管道 | 搜尋/廣告/推薦/能量登錄 | 必填，用於獲客分析 |

### 步驟 2：了解核心需求（5 分鐘）

詢問以下問題：

```
1. 請問目前主要使用哪種文件？（外部合約 / 內部表單 / 公開表單）
2. 主要的簽署對象是誰？（客戶 / 員工 / 廠商）
3. 一個月大約有幾份需要簽署？
4. 目前用什麼方式處理？（紙本 / 競品 / 無）
```

**如果是競品用戶（尤其點點簽）：**
```
5. 目前用哪個服務？合約什麼時候到期？
6. 主要不滿意的地方是什麼？（費用 / 卡頓 / 功能）
```

### 步驟 3：評估潛力等級

| 等級 | 條件 | 動作 |
|------|------|------|
| 🔴 高潛力 | 月份數 >100 份 OR 員工 >50 人 OR API 需求 | 立即電話聯繫，優先開體驗版 |
| 🟡 中潛力 | 月份數 20~100 份，明確需求 | 發說明資料，邀請試用 |
| ⚪ 低潛力 | 月份數 <20 份，需求模糊 | 僅留 mail，自動流程跟進 |
| ➡️ 轉介 | 需 BPM / ERP 整合 OR 大型 Enterprise | 轉 Kelly 處理 |

### 步驟 4：推薦方案

根據員工人數快速對應：

| 人數 | 推薦方案 | 月費 | 年費 |
|------|----------|------|------|
| 1 人 | 專業版 | NT$300 | NT$3,000 |
| 2~5 人 | 企業版 | NT$1,500 | NT$15,000 |
| 6~20 人 | 企業版（加人）| 依人數 | 依人數 |
| 21~50 人 | 企業版 | 依報價 | 依報價 |
| >50 人 | Enterprise / API | 需詢價 | 需詢價 |

### 步驟 5：開通體驗版（高/中潛力）

1. 登入後台，升級客戶帳號為企業方案體驗版
2. 設定試用期（預設 14 天，特殊情況可延至 30 天）
3. 發送歡迎 Email（附快速入門資料）
4. 記錄到期日，設置提醒

### 步驟 6：記錄日報

在當天日報中填寫完整資訊（參考日報格式），包含：
- 來源管道（必填）
- 需求描述
- 下一步動作
- 試用到期日

---

## 驗證完成

- 日報已填寫來源管道欄位 ✓
- 體驗版已開通（如適用）✓
- 下一步動作已確認並記錄 ✓

---

## 出問題時怎麼辦

**客戶無法升級體驗版** → 確認 Email 是否與帳號綁定正確，若無法處理聯繫技術

**客戶詢問技術細節（API / SSO / Docker）** → 收集需求後轉 Kelly 或技術窗口

**客戶要求超長試用（>30 天）** → 需 Alex 確認後再開通

---

## 有問題？

- 業務流程問題 → 詢問 Kelly
- 系統帳號問題 → 聯繫技術支援
