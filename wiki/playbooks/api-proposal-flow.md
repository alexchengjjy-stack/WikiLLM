# API 方案報價 SOP

> **API 方案涉及技術評估與業務談判雙軌並行，錯誤的方案會導致技術工期爆炸或業務流失。**

## ✅ 完成定義

- [ ] 確認客戶的技術整合場景
- [ ] 確認預估年份數（決定 AATL 單價）
- [ ] 提供正式書面報價
- [ ] 確認對方技術窗口與業務窗口

---

## 何時使用

當客戶詢問 API 整合、系統串接、或 ISV / SI 合作報價時

---

## 前提條件

- 對方已有明確的系統整合需求（ERP / HIS / BPM / 自建系統）
- 已確認決策者或技術窗口

---

## 流程

### 步驟 1：需求釐清（技術面）

確認以下技術問題：

```
1. 貴公司想串接哪個系統？（ERP / HIS / BPM / 自建網站）
2. 主要需要哪種簽署功能？
   □ 遠距簽（Remote Sign）
   □ 現場簽（On-site Sign）
   □ 公開表單（Public Form）
   □ 雲端憑證（AATL）
3. 預估一年約有幾份文件需要簽署？
4. 有無特殊需求？
   □ SSO 單一登入
   □ Docker 地端部署
   □ 特殊 OTP 驗證方式
   □ 電子印章（需確認使用場景合規性）
```

### 步驟 2：需求釐清（業務面）

```
5. 貴公司的客戶數量大約多少？
6. 這個 API 是要服務貴公司自己，還是要轉賣給你們的客戶？
7. 預計什麼時候上線？時程壓力如何？
```

> ⚠️ **注意**：若客戶要「轉賣給其客戶」，屬於通路合作模式，報價邏輯不同，需另外討論分潤機制（如鼎新 7/3 拆帳）。

### 步驟 3：初步報價（標準方案）

#### 基礎 API 年費方案

| 方案 | 年費 | 含 AATL 份數 | 超額單價 |
|------|------|--------------|----------|
| 小型（ISV）| $3,000/年 | 100 份 | $30/份 |
| 標準 | $10,000/年 | 300 份 | $30/份 |
| 大型 | $15,000/年 | 500 份 | $25/份 |
| 企業定制 | 詢價 | 定制 | 定制 |

#### AATL 大量預付（獨立購買）

| 份數 | 單價 | 備註 |
|------|------|------|
| 100~1,000 份 | $30/份 | |
| 1,001~5,000 份 | $25/份 | |
| 5,001~10,000 份 | $20/份 | |
| 10,001 份以上 | 詢價 | |

#### 醫美 / 大量簽署專案（階梯報價）

| 份數範圍 | 單價 |
|----------|------|
| 1 ~ 40,000 份 | $16/份 |
| 40,001 ~ 80,000 份 | $14/份 |
| 80,001 份以上 | $12/份 |

### 步驟 4：提供正式報價單

1. 以 Email 發送 PDF 報價單（含稅 / 未稅明確標示）
2. 報價單有效期：30 天
3. 同時提供 API 技術簡報（含 createTaskUrl、AATL 流程說明）

### 步驟 5：技術對接安排

若客戶確認意願：

- [ ] 提供 API 文件連結
- [ ] 建立技術討論群組（Line / 微信 / Email）
- [ ] 確認測試帳號 Private Key
- [ ] 安排技術討論會議（BZS 技術 + 客戶開發端）

---

## 驗證完成

- 需求確認表已填寫 ✓
- 正式報價已發送 ✓
- 技術窗口已確認 ✓

---

## 出問題時怎麼辦

**客戶要求「電子印章」取代自然人簽名** → 解釋合規紅線，評估場景是否可行（詳見[電子簽章顧問技能](../skills/electronic-signature-consulting.md)）

**客戶要求 Docker 地端部署** → 需轉 Alex 確認技術可行性與授權費用

**客戶在大陸有 VPN 需求** → 說明 OTP 替代方案，轉技術評估

**客戶要求「多次暫存後一次 AATL 封裝」** → 此為特殊需求，需技術評估工期與額外費用
