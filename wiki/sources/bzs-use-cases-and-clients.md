# BreezySign 好好簽實際案例和場景

> 本文件彙整了好好簽在各行各業的實際導入案例，詳列了各產業的常見合約類型、導入痛點，以及客戶最常使用的特定簽署功能（如：Line 傳簽、錄影簽、公開表單等）。

## 核心要點
- **功能對應產業痛點**：不同產業對電子簽章的需求不僅僅是「簽名」，更依賴特定的交付與驗證方式（例如：貸款業依賴 Line 傳簽與錄影、租車業需上傳證件）。
- **五大主力垂直產業**：建設不動產、金融貸款代辦、旅行業、醫療長照、租車業。

## 詳細內容

### 1. 建設 / 不動產行業
- **代表客戶**：陸府建設、大瀚環球、和仕集團、拓點商用不動產、興城團隊、阜東不動產、全球不動產等。
- **簽署文件**：房屋買賣契約、長短租租賃合約、委託書、預售屋紅單。
- **應用場景與主推功能**：
  - **遠端簽**：發送 email 給外縣市客戶簽署。
  - **現場簽 (面對面)**：客戶到場時，業務在平板上解說合約並直接讓客戶簽名。
  - **聲明錄影簽**：用於高金額的買賣合約，保留錄影檔以防後續爭議。

### 2. 金融與貸款代辦業
- **代表客戶**：聚利國際理財、富達商業、宮銘管理顧問、富邦國際、鼎祥財經等。
- **簽署文件**：委辦貸款合約書、放款協議、代辦委託書。
- **應用場景與主推功能**：
  - **Line 傳簽 / 簡訊簽**：消費者（年輕人或一般大眾）通常沒有或不常收 email，透過手機號碼與 Line 發送最為有效。
  - **聲明錄影簽**：金融屬性極需防範詐欺與爭議，錄影確認客戶本人是剛需。

### 3. 旅行業
- **代表客戶**：林軒旅行社、三達國際旅行社、白雪公主旅行社、黎海岸國際旅行社、富友旅行社等。
- **簽署文件**：旅遊定型化契約、安全協議書、刷卡單。
- **應用場景與主推功能**：
  - **Line 傳簽**：直接傳給參加旅行團的消費者。
  - **公開表單簽 + Webhook**：將公開表單連結放入 Google 表單或內部訂單系統，收到客戶訂單後，自動發送專屬 URL 給用戶簽署（自動化流程）。

### 4. 租車業
- **代表客戶**：豐盛富足資產管理、羽倢有限公司。
- **簽署文件**：機車出租合約、租車行程合約。
- **應用場景與主推功能**：
  - **附件上傳 (身份證/駕照)**：客戶除了簽名，還需填寫個資並上傳身分證件。
  - **Line 傳簽**：方便旅客在現場或抵達前快速完成手機簽署，且保留軌跡。

### 5. 健康管理與醫療長照
- **代表客戶**：樂橙職業健康管理、季灃健康服務、富爾達健康事業等。
- **簽署文件**：服務記錄表、醫療服務合約、健康管理資料。
- **應用場景與主推功能**：
  - **多方會簽**：內部審核 -> 發起人 -> 主管用印 -> 客戶承辦人 -> 客戶主管，支援複雜的簽核站點設定。
  - 一次夾帶多份 PDF 一併簽署。

### 6. 行銷、物流與商品批發
- **代表客戶**：雲數位智能行銷、京承行銷、捷風創意、極曜行銷、日商樂比亞等。
- **簽署文件**：勞務報酬單(B2C)、委刊單(B2B)、設計廣告合約、保密協議。
- **應用場景與主推功能**：
  - **批次發送**：處理大量且個資不同的網紅勞報單。
  - **身分證上傳**：簽署勞報單時一併要求員工/接案者拍照上傳證件。
