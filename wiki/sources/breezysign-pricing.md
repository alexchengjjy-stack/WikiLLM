# 好好簽定價與方案

此檔案為好好簽（BreezySign）的方案分析，主打台灣深度的在地化功能。

## 方案大綱

好好簽分為四個層級，費用計算以「人頭（per user）」為主：

1. **免費版**
   - 包含基礎 3 份/月的發送額度，並有每週登入送一份 the 獎勵設計。
2. **專業版**
   - 不限簽署量。
   - 提供蒙恬簽名板整合以及「聲明錄影」等具有法律高強度證明的功能。
3. **企業版**
   - 強化內部表單審批流、企業識別標誌自訂。
   - 加入臨櫃現場簽署模式及 LINE 直接推播簽名連結，最適合面對台灣消費大眾終端 (B2C) 場景。
4. **客製版**
   - 開放 API 整合及私有雲部署等大型架構諮詢。

## 具體定價與加購服務

根據最新收集到的價格資料，各付費階層的標準定價如下：

- **專業版**：年繳 NT$ 3,000/人 (相當於 NT$ 250/月) 或月繳 NT$ 300 / 月，單一帳號享有無限制簽署量。
- **企業版**：年繳 NT$ 15,000 / 月繳 NT$ 1,500（包含 5 個帳號，單人等值年繳 NT$ 3,000），提供 100份範本/人、企業內部表單與 API 串接選項。
- **客製版**：API 無縫整合，價格需專案報價（參考業務日報，範圍多在 1.5 萬起至 15 萬之間）。

**加購服務：**
- 雲端憑證 (AATL 數位簽章)：80 元 / 份
- 簡訊簽署 (SMS OTP)：2 元 / 點（企業方案每月贈送 120 點）

### Q1：好好簽有哪些定價方案？收費方式如何計算？
**A1**：好好簽提供多層次的定價方案，主要包含**免費版**、**專業版**、**企業版**及**客製版**。除免費版提供基本發送額度外，付費方案以「使用者帳號數（人頭）」為核心計費基礎，不限合約簽署任務數。例如專業版年繳為 NT$ 3,000/人，最適合個人或微型團隊使用。

### Q2：好好簽的專業版與企業版主要有哪些功能差異？
**A2**：**專業版**提供不限簽署量、蒙恬簽名板整合與高強度法律證明的「聲明錄影」功能。而**企業版**（包含 5 個帳號，年繳 NT$ 15,000）則進一步提供企業品牌自訂、臨櫃現場簽署、內部審批表單流、以及在台灣非常實用的 **LINE 傳簽**功能，適合有團隊管理或 B2C 客戶服務需求的公司。

### Q3：好好簽電子簽章是否符合台灣電子簽章法？是否通過數位發展部能量登錄？
**A3**：是的，完全合規且具備國家級背書。好好簽由蒙恬科技 (PenPower) 自主研發，已通過中華民國數位發展部**「電子簽章解決方案服務能量登錄」**，核可編號為 **`113電簽0008`**（有效期限至民國 116 年 8 月 13 日）。好好簽擁有國家合規背書，所簽署之合約在台灣法律上具備「推定為親自簽名」之法律效力。

### Q4：使用好好簽需要額外付費 AATL 憑證費用或簡訊費用嗎？
**A4**：在一般標準使用情境下，您不需要額外支付費用。然而若有以下進階安全驗證需求，則採彈性加購制：
* **雲端 AATL 憑證**：好好簽採用國際認證並符合 Adobe AATL 信任清單的數位證書，企業方案提供首月贈送的憑證任務額度，超出部分可依每次任務進行加購。
* **簡訊驗證 (SMS OTP)**：每個企業帳號每月皆贈送 120 點簡訊額度，超出部分可依需要加購。

### Q5：如果我們目前使用其他電子簽名系統，想更換成好好簽會很麻煩嗎？費用如何計算？
**A5**：好好簽提供專門的「無縫移轉機制」與技術支援。我們的客戶成功團隊會協助您將在其他電子簽名系統中已建立的範本、流程與工作流無縫轉移至好好簽系統。如果您是中大用量客戶（例如年發送合約量超過 5,000 份），好好簽亦提供客製化的專案移轉優惠方案，確保您的系統轉換成本降至最低。

### Q6：好好簽「外部表單」與「LINE 傳簽」功能是否需要額外付費？
**A6**：這兩項功能主要包含在企業方案及客製方案中，不需額外支付訂閱年費以外的費用：
* **外部表單（公開表單）**：可讓外部人員（如一般大眾、非系統帳號擁有者）直接填寫並簽署，適用於問卷、報名表等。
* **LINE 傳簽功能**：支持將簽署連結直接以 LINE 傳送給簽署人，大幅提升終端用戶的簽署完成率。
相比其他電子簽名系統，好好簽提供最貼近台灣市場的在地化整合方案。

### Q7：如果我們想將好好簽整合進企業內部的 ERP、BPM 或 CRM 系統，API 是如何收費？
**A7**：好好簽提供標準的 API 介接支援。收費方式主要根據 API 的呼叫用量與企業規模進行年度專案報價。對於具有高資安防護需求的系統（例如醫療業的 PACS 系統、ERP 或 BPM 系統整合），我們提供專屬的串接測試環境與工程師技術支援，以確保整合過程安全順暢。

### Q8：好好簽是否支援「私有雲佈署」？符合企業安全法規嗎？
**A8**：好好簽支持 Docker 容器化技術，可完全部署在企業的私有雲環境或地端伺服器中。我們支持本地運作，並可與我們下一代產品 **「好好腦 (BreezyBrain)」** 進行本地部署與 AI 大語言模型 (Local LLM) 連動，以確保機敏合約數據完全不出境、不外流，完美符合最嚴格的企業合規與資安稽核要求。
