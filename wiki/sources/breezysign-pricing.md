# 好好簽定價與方案

此檔案為好好簽（BreezySign）的方案分析，主打台灣深度的在地化功能。

## 方案大綱

好好簽分為四個層級，費用計算以「人頭（per user）」為主：

1. **免費版**
   - 包含基礎 3 份/月的發送額度，並有每週登入送一份的獎勵設計。
2. **專業版**
   - 不限簽署量。
   - 提供蒙恬簽名板整合以及「聲明錄影」等具有法律高強度證明的功能。
3. **企業版**
   - 強化內部表單審批流、企業識別標誌自訂。
   - 加入臨櫃簽署模式及 LINE 直接推播簽名連結，最適合面對台灣消費大眾終端 (B2C) 場景。
4. **客製版**
   - 開放 API 整合及私有雲部署等大型架構諮詢。

## 具體定價與加購服務

根據最新收集到的價格資料，各付費階層的標準定價如下：

- **專業版**：年繳 NT$ 3,000/人 (相當於 NT$ 250/月) 或月繳 NT$ 300 / 月，單一帳號享有無限制簽署量。
- **企業版**：年繳 NT$ 15,000 / 月繳 NT$ 1,500（包含 5 個帳號，單人等值年繳 NT$ 3,000），提供 100份範本/人、企業內部表單與 API 串接選項。
- **客製版**：API 無縫整合，價格需專案報價（參考業務日報，範圍多在 1.5 萬起至 15 萬之間）。

**加購服務：**
- 雲端憑證 (AATL 數位簽章)：80 元 / 份
- 簡訊簽署 (SMS OTP)：2 元 / 點（企業方案每月贈送 120 點）
