# 好好簽 (BreezySign) 2026 業務日報萃取與綜合摘要

> 本文件彙整自 `raw/BZSdata` 下超過 50 份的 2026 年專案及 SaaS 業務日報。展示了好好簽在市場上的真實定位、商業模式擴展，以及潛在的產品擴充需求。

## 市場與產業應用場景

從大量的 Inbound 與開發客戶名單中，可以發現好好簽主力著重在以下幾種產業：

1. **醫療與生技診所 (重點發展)**
   - **應用場景**：醫美診所同意書、臉譜圖畫圖、基因檢驗同意書、產學合作人體檢驗同意書。
   - **整合系統**：長期與「方鼎」、「得勝者」以及「耀聖資訊」等 HIS (醫療資訊系統) 廠商串接，推行 API 方案。診所有對於「雲端與地端 NAS 備份」的混合需求。
2. **中大型企業內部簽核 (BPM/ERP對接)**
   - **應用場景**：人資入職文件與保密協議、採購合約、經銷商合約、網紅直播主經紀合約。
   - **痛點與回饋**：許多客戶原有 BPM (如人易) 功能太基本，因此尋求整合電子簽章。但企業對於**地端佈署 (Docker)**、**SSO (單一登入)**有一定要求，並強烈要求具備 **SLA (Service Level Agreement) 監控機制**與**逾時催辦提醒功能**，以完善工作流控管。
3. **特約合作與空間租賃**
   - **應用場景**：商務中心 (Coworking space) 線上簽約、企業與特約廠商的大量合作協議簽署。

## 定價與商業模式解密

相較於外部公開資訊，業務日報中披露了對企業端與 API 客戶的真實計價模式：

- **API 基本年費**：表定 $15 萬/年，或針對小型專案以 $15,000/年含 300 份簽章的套裝起步。
- **AATL 數位憑證計費 (用印費)**：
  - 小量單價：約 $30/份（如台塑一年 1,000 份，共 3 萬）
  - 專案量大單價：依數量距 $20 ~ $25/份不等 (例如亞洲志遠一年一萬份，初報 $25/份；2000 份約 $50,000)。
  - 对比資訊：日報中提及點點簽 (DottedSign) 的報價約落在 $27 ~ $40，顯示好好簽在價格上採取貼身肉搏或略具優勢的策略。
- **點點簽漲價與跳槽效應**：多份日報（如富友旅行社、鼎祥財經、麻吉行得通、聖美麗健康管理顧問等）指出，點點簽近期將「人數計價」全面改為「合約數計價」且大幅調漲（如商務版 500 份/年，約 NT$25,000），這股推力非常強烈，甚至有客戶在點點簽合約尚未到期前數個月，就已積極尋找替代方案並申請好好簽企業版試用以利後續轉換。然而也有客戶（如言果學習）為規避份數限制，选择 5 人共用一個無份數限制的點點簽專業版（個人版，USD96/年）。此外，客戶也頻繁反映點點簽在處理合約時出現系統卡頓與載入過久的問題，反饋好好簽使用較為順暢。
- **簡訊發送費**：$2/則。

## 生態系夥伴與通路佈局

好好簽相當依賴策略夥伴 (SI/ISV) 將電子簽章作為模組嵌入現有系統：

1. **鼎新電腦**：針對中大型製造與零售業（台灣 2 萬家、大陸 4 萬家），採「70% (好好簽) / 30% (鼎新)」的拆帳模式。不僅上架鼎新雲市集 (SaaS展售)，更與鼎新的 **AI 諸葛平台** 透過 API 整合（採點數計價）。並預告未來將轉向「業務中台」模式，開放 MCP 框架供各廠商自行開發上架。
2. **百加資通 (101Form)**：台灣知名的 BPM 系統商。
3. **得勝者 / 方鼎**：專攻醫療診所的簽章與資安備份套餐。
4. **政府計畫與國際接軌（工研院）**：受數發部委託，工研院邀請好好簽（蒙恬）參與台灣電子簽章對齊國際標準的技術檢測與跨境應用試點（參考歐盟 DSS 開發技術檢測工具），為產品提供官方背書與出海機會。

## 產品發展與技術抗性

- **合規性與憑證標準**：客戶頻繁詢問 AATL 綠勾勾的必要性與法律效力，許多診所內部用表單被說服不需 AATL，省下成本；高風險合約則強制使用。
- **企業需求與技術挑戰**：中大型集團對於「主子帳號共用範本與 API 權限管理」、「防範信箱塞爆的指定收件人功能」、「隱藏簽署標籤 (Tag)」以及「Docker 地端防護」的呼聲很高。
- **跨國連線與防護爭議**：如鼎新客戶在大陸面臨 VPN 連線阻礙，需評估替代 OTP；又如合信因系統升級與防火牆誤判，導致簽名 IP 紀錄全在美國，引發客戶對軌跡合法性的擔憂。
- **進階與特殊 API 需求湧現**：隨著業務拓展，出現如泰瑞醫尋求「AI 錄音王」硬體串接 Web API、聯合線上詢問「公開表單」API 化、以及采盟數位要求「多次簽名暫存後再一次 AATL 封裝」的複雜軌跡需求。同時，傳統製造業 (如堃霖) 要求整合 T100 ERP 與 HR 系統時，也開出了具備 SLA 管制的 BPM 對接需求。
- **「外部表單」成為差異化武器**：面對複雜情境（如凌越生醫 20 份以上文件、多關卡並簽 or ），好好簽的「外部表單」功能成為擊敗點點簽與 iLovePDF 等缺乏此功能競品的關鍵。
- **特定產業的影像簽章需求（競品流失）**：部分對身分驗證極度敏感的客戶（如第一建經），因為需要「邊簽邊錄影」以確保簽署人身分，最終選擇了主主打此功能的競品（雲想科技）。
- **Line 傳簽與輕量化軌跡需求**：例如豐盛富足資產管理（租車行程合約）與云行銷企業社，皆因需要雙方皆有完整的軌跡記錄與低阻力的簽署體驗，最終轉向以「Line 傳簽」為核心應用場景，成功推動小微企業付費訂閱。
- **大檔案上傳與憑證觀念落差**：醫療等產業因掃描大量紙本（如護理師上傳資料），常遇到超過 10MB 單檔限制（達 27~28MB）的痛點。此外，用戶常誤以為多份 PDF 一次簽完後可「合併」下載，不理解因為每份檔案各自嵌入 AATL 數位憑證，在技術上無法合併的限制。**內部決策**：AATL 嵌入技術限制（嵌入過大檔案容易失敗）已成為拒絕特定醫療客戶（如聖美麗健康顧問）的正式理由，即使因此流失該客戶。
