# eIDAS 2.0 — 歐盟數位身分框架

> 本文彙整自 `raw/eIDAS 2.0/` 下共 7 份來源文件，涵蓋法規文本、入門指南、技術標準分析與產業應用實例。

---

## 什麼是 eIDAS 2.0？

**eIDAS 2.0**（Regulation EU 2024/1183）是歐盟對 2014 年原始 eIDAS 法規（EU 910/2014）的重大更新，全名為「電子識別、認證和信任服務 2.0」。於 **2024 年 4 月 30 日**正式刊載於歐盟官方公報，**2024 年 5 月 20 日**起生效。

其核心目標是建立一套覆蓋全歐盟的**數位身分基礎設施**，讓公民與企業能在所有成員國之間無縫驗證身份、簽署文件、存取公私服務。

---

## 核心創新：歐盟數位身分錢包 (EUDI Wallet)

最重要的新增機制是 **EU Digital Identity Wallet (EUDI Wallet)**：

- **強制部署**：各成員國必須在 **2026 年底前**向公民提供數位身分錢包
- **適用範圍**：全體歐盟公民、居民及企業
- **功能**：儲存與管理駕照、醫療證書、學歷文件、銀行帳號等屬性憑證
- **隱私設計**：本地端儲存，用戶完全控制資料分享範圍（零追蹤設計）
- **免費使用**：發行、使用及吊銷對自然人均免費

> [!IMPORTANT]
> 超大型線上平台（VLOP，如 Amazon、Facebook、Booking.com）以及特定公私服務**必須接受 EUDI Wallet 進行身份驗證**，這是市場強制義務。

---

## eIDAS 1.0 vs eIDAS 2.0 主要差異

| 維度 | eIDAS 1.0（2014） | eIDAS 2.0（2024） |
|------|------------------|------------------|
| **適用對象** | 公共服務為主 | 公共 + 私人服務（含私人平台） |
| **數位錢包** | 無 | 新增 EUDI Wallet（強制部署） |
| **信任服務** | 電子簽名、印章、時間戳記 | 新增電子存檔、電子帳簿、屬性憑證 |
| **跨境互通** | 互相承認機制（有漏洞） | API 驅動、全面互通 |
| **義務對象** | 成員國 | 成員國 + VLOP + 特定私人實體 |
| **隱私控制** | 基礎 | 強化隱私儀表板、選擇性揭露 |

## 信任服務類型

eIDAS 2.0 定義的信任服務（Trust Services）包括：

| 服務類型 | 說明 |
|---------|------|
| **電子簽名 (Electronic Signature)** | 法律效力等同手寫簽名（最高等級：合格電子簽名 QES） |
| **電子印章 (Electronic Seal)** | 法人/組織用，確保文件來源與完整性 |
| **電子時間戳記** | 確立文件建立或傳送的精確時間 |
| **電子掛號遞送** | 具法律效力的收發確認（類似掛號信） |
| **網站身份驗證** | QWAC 憑證確保網站真實性 |
| **電子存檔** | 新增，長期保存文件的法律效力 |
| **電子帳簿** | 新增，區塊鏈等分散式帳本的法律認可 |
| **屬性憑證 (QEAA)** | 新增，數位化學歷、資格證書等屬性的可驗證憑證 |

---

## 電子簽名等級（與台灣電子簽章法對照）

```
合格電子簽名 (QES) ← 最高法律效力，等同手寫簽名
    ↑ 需使用合格信任服務提供者頒發的合格憑證 (QC)
    ↑ 搭配合格電子簽名創建設備 (QSCD)

進階電子簽名 (AES) ← 強加密、法律效力強但非 QES 等級
    ↑ 靈活加密手段（軟私鑰），適合大多數商業場景

普通電子簽名 (Simple ES) ← 基礎，e.g., 掃描簽名、OTP 確認
```

> [!NOTE]
> 台灣的「數位簽章」（具備 CA 憑證的 AATL 等級）大致對應歐盟的 AES 或 QES 等級，在 2024 年台灣修法後同樣具備法律推定效力。

---

## 技術標準

eIDAS 2.0 以 **ETSI 標準**為技術支柱：

- **ETSI EN 319 401**：信任服務提供者通用安全要求
- **ETSI TS 119 461**：身份驗證技術規範
- **架構參考框架 (ARF)**：歐盟委員會與成員國協作制定的 EUDI Wallet 技術架構

## 主要實施時程

| 時間點 | 里程碑 |
|--------|--------|
| 2024-05-20 | 法規正式生效 |
| 2024-11-21 | 委員會必須建立 EUDI Wallet 技術規範與認證程序 |
| 2024-11-28 | 委員會通過 5 項核心實施法規（數位錢包核心功能、認證框架） |
| 2025-07-30 | 7 項新實施法規通過（信任服務相關） |
| 2025-09-29 | 電子掛號遞送互通性法規通過 |
| **2026 年底** | **各成員國必須向公民提供 EUDI Wallet** |

## 對電子簽章產業的影響分析

### 對台灣廠商（好好簽/BreezySign）的潛在意義

1. **跨境業務機會（工研院 DSS 試點）**：工研院受數發部委託，邀請好好簽（蒙恬）參與台灣電子簽章對齊國際標準（參考歐盟 DSS）的技術檢測與跨境應用試點。eIDAS 2.0 成為台灣廠商接軌國際的參照標準。

2. **AATL 憑證的歐盟對應**：好好簽的 AATL 數位憑證（第三方 CA 認證）可視為進階電子簽名（AES）等級，符合歐盟大多數商業場景的合規需求。若未來欲進軍歐洲市場，需評估升級至 QES 等級的成本。

3. **企業客戶跨境需求**：部分客戶（如鼎新、合信）已面臨跨國連線挑戰，eIDAS 2.0 的互通性框架若成熟，有助於台灣電子簽章服務建立跨境信任基礎。

### 對競品格局的影響

- **Docusign / Adobe Sign**：作為國際廠商，必須符合 eIDAS 2.0 的 QES 等級要求，同時被 VLOP 強制義務要求整合 EUDI Wallet。
- **本土廠商**：目前台灣四大廠商均通過數發部能量登錄，為國內市場的「白名單」；但在歐盟市場，需進一步取得 QTSP（合格信任服務提供者）資格。
