# BreezySign 好好簽 2026-06-08 業務與專案日報

> 本日報涵蓋 SaaS 續約與 API 專案 10 項進展，包含重要的壹端-大瀚第二年續約發票開立（NT$26,500），以及多個在途技術問題確認與跟進。

## 核心要點

### SaaS 業務

**中華-沈氏藝術（續約確認）**
- BZS 訂閱 6 月底到期，已確定辦理續約
- 提供含稅報價：10 人企業版（NT$25,500）、20 人企業版（NT$34,000）

**福安（SaaS 轉案，55 人報價）**
- 初期先使用 SaaS 方案，明年才考慮 API 串接
- 需求 55 人報價，因申請政府補助需要合約與能量登錄許可證明
- 已轉 Jack 負責

### API 專案

**天元（帳號遷移）**
- 主帳號請求從舊 yahoo 信箱換成新 gmail 信箱
- Hank 已於後台修正完成

**加點**
- 提供 API 金鑰（API KEY）取得方式的文件參考

**101 BPM（現場簽功能討論）**
- 舉行線上會議，討論現場簽支援審核功能規格

**壹端-大瀚（第二年發票開立）⭐**
- 開立第二年續約發票：年費 NT$25,000 + AATL 預付 150 份 × $10 = **NT$26,500（未稅）**

**合信（OTP 與 IP 限制）**
- (1) OTP 發送異常問題：BZS 提供 log 紀錄與 Server 解析資訊供查核
- (2) IP 記錄與簽署限制：BZS 將限制僅能於台灣境內 IP 進行簽署，預計於下一版本更新

**棋勝汽車（整合測試帳號開通）**
- 帳號已開通整合測試環境（兩個月期限）
- 目前仍在拉框規劃，範本建立完成後將用操作員帳號進行測試

**如海投資（財團法人敬典文教基金會）（新案）**
- 需求電子簽核、電子簽名與文中 NHR（員工健康）系統串接
- 電話未聯繫上，改用郵件了解需求

**元家企業股份有限公司（結案）**
- 冷凍水產進口與加工龍頭企業
- 內部評估後，BZS 公務門號申請量較少，考量建置效益，暫不推進電子化，維持紙本作業

## 詳細內容

本日最重要的財務事件為**壹端-大瀚第二年發票開立（NT$26,500 未稅）**，確認此客戶已進入第二年續約週期。另外，合信的 IP 境內限制功能排入下一版本更新，顯示有 API 客戶對地理訪問控制有需求，是未來功能溝通的重要依據。元家企業因用量太少主動結案，符合小用量結案的業務決策。
