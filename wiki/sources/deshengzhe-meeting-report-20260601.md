# 得勝者醫療資訊整合專案會議紀錄

> 本次會議紀錄詳細記載了將現有醫療診所地端 HIS/PACS 系統（如展望、方鼎、商之器）透過 API 與電子簽章雲端服務串接之技術規劃。旨在完成同意書簽署、PDF 轉 Dicom 回寫，並遵循衛福部/健保局電子病歷合規要求，同時制定「小額無期限體驗包」等市場推廣策略。

## 5 大核心觀點

### 1. 「座標 + API」與 Dicom 自動轉存整合
雙方定案以「地端計算簽名座標 ➡️ 雲端服務據以產生簽名框並完簽」作為技術對接標準，減少前端人工拉欄位排版之摩擦。簽署完成後，由商之器系統將 PDF 自動轉換為 Dicom 格式並回寫 PACS/HIS 系統，省去傳統下載後再手動同步 Google Drive 的繁瑣程序。

### 2. 混合雲離線暫存與時間戳記合規設計
針對診所地端因偏鄉或網路不穩之斷線情境，規劃在診所地端部署輕量中繼程式。該程式能於斷線時暫存已簽文件，待網路恢復連線後，自動與中華電信時間伺服器（NTP）校時並完成上傳。此設計完全符合電子病歷與電子簽章法規「可離線但不可任意修改、需在 3 天內完成校正」的時間戳記要求。

### 3. 「醫療無紙化推廣策略」── 小額無期限體驗包
針對對年約、大量份數簽署（如 500~3,000 份）存有預算與適應抗性的診所醫師，推出低門檻（50-100 份）、高單價但「無使用期限」的體驗方案（例如 100 份收費約一至二千元）。引導醫師先體驗電子簽名的便利性，待其產生操作習慣且無法退回紙本時，再導入常規的年約型大量包，降低 SLG（Sales-Led Growth）推廣的破冰摩擦。

### 4. 醫療資安監管加強與市場契機
因應近期「愛立美偷拍事件」，衛生局與健保局加強對醫美、自費診所的資安與自我檢查稽核。此舉促使診所對電子存證、時間戳記及合規電子病歷的需求顯著提升，使無紙化與電子簽章在醫美、眼科（白內障手術多表單場景）等高自費科別的滲透率迎來市場爆發期。

### 5. 三方打包銷售與 8 月聯合 Seminar
銷售模式定案由「資安整合商 + 方鼎 (HIS) + 商之器」共同包裝成「診所系統 + 電子病歷 + 電子同意書」整套方案銷售。目前以盧森眼科（搭配方鼎與商之器）作為第一個示範點，預計 6-7 月完成測試與正式上線。8 月份將以此成功案例進行三方聯合 Seminar 醫療無紙化推廣。
