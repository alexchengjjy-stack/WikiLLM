# 好好簽 2026-06-05 業務與專案日報

> 本來源為好好簽 2026-06-05 當日之業務與技術專案日報。日報內容廣泛涵蓋了醫療 HIS 與影像系統串接、中古車集團轉單談判、政府機構 On-premise 部署安全性評估以及多個 Onboarding 專案進程。

## 核心要點
- **得勝者 PACS 與醫療整合方案**：研擬支援座標 + API，討論混合雲/離線中繼校時方案（遵循電子病歷離線 3 天內校正規範）。推出無期限體驗包（50-100份，一至兩千元），以「盧森眼科」為首波示範站（6-8月上線）。協助診所因應愛爾麗監視器事件進行資安自我檢查。
- **棋勝汽車轉單跟進**：中古車集團年預估量 2,000 份。點點簽利用人脈關係報價 $48/份，我方以 AATL $30/份及具備民國年格式、高 API 熟悉度競爭中，已介紹 OCR 技術。
- **美力時尚診所簽約**：5,000 份 AATL $80,000 含稅成交，超額季結。與電子病歷一起送簽，商務合約分開，11/1 上線，已提供子公司清單 API 用以區分分店用量。
- **勞動部 On-premise 報價與疑慮**：報價 BZS On-premise 156 萬，MA 45.9 萬(未稅)。暫無 AATL 需求，文件加蓋勞動部憑證。客戶提出重要資安/法規質疑：目前 BZS 簽名與錄影為分開檔案、未嵌入 PDF，法律糾紛難以佐證。
- **經銷商「吉格線」醫院同意書案**：吉格線協助地區醫院建置 AI 導覽，臨時提出同意書電子化。第一階段 SaaS，第二階段 API。提供 10 人版與 20 人版經銷與牌價報價。
- **101 客戶 BPM 地端專案**：回溯檔名由 BPM 給、刪除通知信、名稱同 Email 顯示問題等測試反饋。要求 Hank 協助補齊完成版建置計劃書、弱點掃描報告、討論線上會議替代驗收。
- **星鴻高雄自營品牌**：效法 ERA 與兆基模式，推動高雄不動產自營「電子簽約」，初期以 SaaS 給高雄客戶測試，引導新增公司協作管理。
- **通路與 Onboarding 其他進展**：
  * **軟訊**：BZS 體驗展延至 6/30，近期安排 RD 串接 API。
  * **亞家**：客製化比重高，專案預算高，內部評估中。
  * **和泰**：啟動電子簽章專案，規劃串接 ERP，盤點使用疑慮中。
  * **亞揪遊**：來信需求客製化合作方案，安排會議詳談。
  * **富達商業**：需求 API 方案，安排 6/9 拜訪簡報。
  * **天元**：主帳號信箱換成 `kuma.bamboo20260517@gmail.com`，後台調整但客戶端登入未變，待與 Hank 確認。
  * **合信**：安排技術會議釐清簡訊 OTP 發送異常。已協助恢復因行政疏失 cancel 的任務。
  * **亞洲志遠-天使創投**：需求為 50 位股東共簽一份文件。已婉拒，因客製化變動會引發共用架構連帶影響。
