# 點點簽價格及方案

> 點點簽 DottedSign 是少數走向國際的台灣 SaaS 品牌，因此以美金（USD）計價為核心，且提供強大的 API 整合選項。

## 方案介紹

### 專業方案 (Pro)
- **定價**：USD 15 / 月 (若年繳約 USD 96 / 年)。
- **定位**：針對單一專業工作者（限單人授權）。
- **特色**：擁有無限發送簽署的額度、基本 OTP 驗證以及 1 份常用範本儲存。

### 商務方案 (Business)
- **定價**：USD 200 / 年起（依任務包大小變動）。
- **定位**：團隊與中大企業。
- **強勢特色**：團隊「無人數上限」，費用是依據購買的「任務包數量」決定（基礎 100 份起）。若企業人數多但各自簽署量不高，此方案可幫企業省下驚人的人頭費。
- **功能**：包含批次簽署、臨櫃簽署、工作區管理、權限劃分等。

### 企業客製方案 (Enterprise)
- **定位**：高度整合客群。
- **特色**：包含數位憑證身分驗證、SSO 等高端企業管理需求。原生整合 Google Workspace, Zapier 甚至提供專屬 API 金鑰不須加付額外買斷費用。
