# 律果簽價格及方案

> 律果簽以解決合約法務為出發點，計價方式嚴格採用「人頭制」，分為極具彈性的 5 個層級。

## 方案陣列

1. **個人免費版**
   - 包含基本的自我簽署及極少量的邀請（每月 3 份）。
   
2. **基本版 (Basic)**
   - **定價**：NT$ 180 /月/人 (年繳優惠：NT$ 2,160 /年/人)
   - **額度**：30 份/月 簽署量。
   - 這是尋求擁有法律效力驗證的團隊最容易入門的起點。

3. **標準版 (Standard)**
   - 解鎖大量的合約生命週期管理 (CLM) 特性。支援至少兩組動態審核流程、以及紙本掃描的歸檔與全文檢索。

4. **專業版 (Professional)**
   - **定價**：NT$ 11,760 /年/人
   - **特色**：擁有無限量簽署額度，並完全釋放 CLM 審批動態流程數量限制。最高層級甚至將會搭配法顧方案時數回饋。

5. **企業客製版 (Enterprise)**
   - 提供專屬 API 支援、私有化地端部署，以及如工商憑證與 AATL 等高階憑證驗證服務。

*分析指出，律果簽在低人數、重試錯階段的新創團隊非常友善，且其法務深度遠超出普通簽單工具。*
