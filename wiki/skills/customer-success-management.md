# 客戶成功管理

> 確保 B2B 客戶在購買後能成功落地使用，進而持續續約、擴大採購，並成為口碑推薦來源。此技能以好好簽 SaaS 客戶的完整生命週期為核心場域。

## 核心能力

- **Onboarding 導入**：引導客戶建立第一個範本、發起第一份任務
- **技術問題排解**：解決 API 串接、批次簽錯誤、AATL 合規疑問
- **使用分析**：觀察客戶任務數增長趨勢，識別卡關點
- **升級引導**：從試用版 → 付費版 → 更高規格方案的自然升級路徑
- **續約談判**：建立年費報價、匯款流程、客製化優惠方案
- **口碑管理**：鼓勵客戶推薦同業，建立同行推薦效應

## 客戶生命週期管理

### 試用期（體驗版，通常 14~30 天）
1. 開通當天：發送歡迎 Email + 快速入門資料
2. 第 3 天：觀察是否有任務發起（任務數 = 0 需主動詢問）
3. 第 7 天：詢問使用狀況，提供進階功能介紹
4. 到期前 3 天：主動聯繫報價，提供匯款資訊
5. 到期後：跟進是否需要延長試用或確認購買

**轉換率指標**：任務數 > 10 的客戶，付費轉換率顯著提升

### 付費期（正式訂閱）
- 季度 Check-in：詢問使用狀況與新需求
- 年度報告：整理客戶一年簽署份數、省紙量等 ROI 數據
- 續約前 60 天：提前接觸，避免被競品搶佔

## 常見問題與處理方式

| 問題類型 | 典型案例 | 標準處理 |
|----------|----------|----------|
| 批次簽錯誤 | 自強基金會：批次簽與範本不匹配 | 提供操作說明 + Bug 確認 |
| 下載問題 | 和興：改版後使用者無法下載完成文件 | 暫時回復原方案，通報技術 |
| 範本分享 | 太平洋旅行社：管理帳號能否分享範本 | 說明 SaaS 公版 vs UNIFY 設定 |
| 簡訊未送達 | 合信：三竹無紀錄 | 拉 Log 交叉比對，通報三竹 |
| 附件功能 | 台中浸信會：附件操作不清楚 | 發送圖文操作說明 |

## 口碑效應案例

- 人力仲介業：同行推薦是主要轉換因素（永展國際案例）
- 財團法人體系：教會、基金會決策保守，內部執事需逐級審核
- 旅遊業：點點簽用戶圈中口耳相傳效果強
