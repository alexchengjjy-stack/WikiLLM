# SaaS 業務開發

> 從 Inbound 潛客管理到 Outbound 主動開發，以好好簽（BreezySign）SaaS 業務為核心場域累積的實戰能力。核心在於快速辨識潛客價值、降低試用門檻、並抓住競品漲價帶來的替換視窗。

## 核心能力

- **潛客資格確認（Lead Qualification）**：快速評估 BANT（預算/決策者/需求/時程）
- **試用轉換管理**：企業體驗版到付費訂閱的跟進節奏
- **競品替換銷售**：識別競品弱點（漲價/卡頓），製作對比提案
- **報價策略**：階梯報價、預付方案、年繳優惠設計
- **通路管理**：SI/ISV 合作夥伴開發（鼎新、百加、得勝者）

## 業務情報洞察（從日報累積）

### 客戶決策模式
- **教育訓練業**：用份數少、決策速度快，傾向試用後直接年訂閱
- **醫療生技業**：決策鏈長（承辦→IT→院長），需 Demo + 報價單 + 電子發票
- **不動產仲介**：重視 Line 傳簽與軌跡合規，通常找負責人直接拍板
- **製造業 ERP 對接**：技術需求複雜，需搭配 SI 夥伴一起進場

### 競品替換視窗識別
- 點點簽漲價期與合約到期前 3 個月是最佳切入時機（深入拆解：[[dottedsign-pricing|點點簽定價方案]] 的美金年繳計費與任務包限制）
- 競品出現系統卡頓投訴時，主動聯繫詢問體驗版
- 通路夥伴（如鼎新）推薦為最高轉換率來源

### 關鍵報價技巧
- 企業版：明確列出每月份數 + 超額計費，方便客戶自算 ROI
- API 方案：基礎年費 + AATL 單價，強調「用多少付多少」彈性
- 大量方案：階梯報價（1萬份以下 $16，4萬份以下 $14，以上 $12）

## 工具與流程

- **日報系統**：每日記錄 Inbound 進件、Line 官方諮詢、客戶進展
- **體驗版管理**：開通試用、觀察任務數增長、追蹤到期日
- **CRM 功能**：目前以 Email + 日報為主（無正式 CRM）
