# 吉格線 (GiGOLine)

> 吉格線為好好簽（BreezySign）之系統整合（SI）與經銷代理合作夥伴。目前正協助其醫療客戶（某地區型醫院，暫不便透露名稱）建置 AI 導覽系統，並代該客戶提出同意書與合約無紙化電子簽署的方案與價格諮詢。

## 核心要點
- **醫院同意書電子化專案**：
  * **兩階段導入**：第一階段規劃以 SaaS 模式快速上線，用以解決即時的同意書電子化需求。待 SaaS 運行穩定後，第二階段再行規劃 API 系統串接與自動化歸檔。
- **經銷與授權報價** (含稅)：
  * **10 人版**：牌價 NT$30,000，**經銷價 NT$24,000**。
  * **20 人版**：牌價 NT$40,000，**經銷價 NT$32,000**。

## 詳細內容

### 1. 通路經銷策略
吉格線作為經銷商，能為好好簽切入地區型醫院及公部門醫療機構提供通路。第一階段以 SaaS 模式快速卡位，避開了醫院資訊部門（IT）繁雜的 API 系統評估與資安排程，是縮短銷售週期的良好策略。
