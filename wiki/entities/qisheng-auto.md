# 棋勝汽車

> 棋勝汽車為知名連鎖中古車集團，資本額 2,900 萬元。公司目前使用自行開發的 CRM 系統，其 ERP 系統則為委外開發。目前因應中古車合約無紙化需求，評估導入好好簽（BreezySign）電子合約 API 串接，正與點點簽（DottedSign）進行方案競爭與轉單對比。

## 核心要點
- **轉單競爭大戶**：年預估合約量為 **2,000 份**。時程規劃為 ASAP。我方提供 AATL 憑證報價 NT$30/份。
- **與競品點點簽對比**：
  * 點點簽報價為 **$48/份**（主因棋勝汽車老闆與點點簽高層有私人交情）。
  * 然而，點點簽系統彈性不足（如無法調整合約日期為民國年格式），且其業務對於 API 串接之技術細節不熟悉，此為我方切入之關鍵痛點。
- **OCR 證件與車籍識別**：客戶期望在簽約流程中整合 OCR 技術，用以識別申辦人的身分證、行照、車籍資料表、401/403 報表及存摺封面。客戶目前自行測試 Google OCR 效果表現良好。

## 詳細內容

### 1. 中古車電子合約整合方案
棋勝汽車未來規劃將自身整合好的中古車電子合約系統，轉化為獨立產品銷售給其他中古車行。因此其對 API 的穩定性、合規性及民國年等在地格式化支援度要求極高。我方將協助其開發團隊進行 API 文件引導。

### 2. 轉單防線與跟進
雖然老闆端與點點簽具備私人情誼，但執行層面（IT 與業務）目前因民國年格式問題及點點簽 API 支援能力不足而傾向好好簽。我方需積極提供技術支援與 Sandbox 測試以加速其決策。
