# 神坊資訊股份有限公司 (Symphox)

> 神坊資訊成立於 1999 年，為國泰金融集團成員，資本額約 5 億元。主要提供雲端服務、資訊安全、系統整合與電子商務等解決方案。於 2026 年 5 月主動聯繫好好簽，評估將電子簽章融入網站個人加入特定服務之合約條款同意 API。

## 核心要點
- **大戶 Lead 規模**：資本額 5 億元，公司人數 101~500 人，屬於中大型 B2B Enterprise 客群，極具指標性。
- **特定業務情境**：消費者於網站加入特定服務時，需要勾選或線上同意合約條款，此條款需 100% 符合《電子簽章法》效力，防範未來爭議。
- **最新進展 (小樹購專案)**：旗下電商平台「小樹購」規劃導入 BZS 服務，預估一年簽署 2,000 份。
- **商機報價與回饋**：已提供 BZS 牌價參考（年費 15 萬、AATL $30/份、雲端 $80/份、簡訊 $2/則）。客戶反饋年費 15 萬價格稍高，目前表示仍有議價空間。
- **關鍵需求 (金融實績)**：因其目標客群多為資安敏感度較高的金融業客戶，要求了解 BZS 在金融業合作的實績與資安防護規範。

## 詳細內容

### 1. 商業與場景解析
神坊資訊的需求屬於「聲明同意型 API (Consent API)」或「靜態條款電子簽署」。
這類場景的特徵是：
- **高頻、自動化**：由系統在使用者觸發特定動作（如加入會員、訂閱服務、開通小樹購特定功能）時自動調用。
- **合法合規性大於簽名形狀**：用戶不一定需要親筆手寫，但系統必須產生符合《電子簽章法》規定的 PKI 加密數位簽章與時間戳記，確保自證力與抗否認性（Non-repudiation）。
- **商機規模**：若神坊資訊在其承接的國泰集團專案或自有雲端服務平台中全面導入，其年度合約份數與 API 調用量將非常龐大，具備極高客單價潛力。

### 2. 戰術建議與下一步工作
- **強調數發部能量登錄公信力**：在與神坊資訊洽談時，應重點強調好好簽**已成功通過國家數位發展部【電子簽章解決方案服務能量登錄】**，此為政府公信力背書之最安心通行證。
- **準備金融業實績案例與資安白皮書**：
  - 針對客戶提出的金融客群資安疑慮，主動整理好好簽符合金管會、ISO 27001 資安規範及現有金融/半導體/醫療體系之合作實績。
  - 對標競品點點簽取得之資安標章與大廠案例，提供相對應甚至超越其規格的安全承諾。
- **客製化年費與 AATL 階梯報價**：
  - 神坊目前反映「年費 15 萬偏高」，可依據 2,000 份的預估量，適度調降年費起跳價或將部分 AATL 額度內含於年費中，以「降低首年導入門檻」促成簽約。
- **提供 Consent API 專屬說明書**：準備好針對網站服務條款同意（勾選即簽署/點擊即簽署）的輕量級 SDK 或 API 範例，向其開發團隊證明好好簽 API 具備零阻力整合優勢。
