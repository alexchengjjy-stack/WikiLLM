# 神坊資訊股份有限公司 (Symphox)

> 神坊資訊成立於 1999 年，為國泰金融集團成員。主要提供雲端服務、資訊安全、系統整合與電子商務等解決方案。於 2026 年 5 月主動聯繫好好簽，諮詢將電子簽章融入網站個人加入特定服務之合約條款同意 API。

## 核心要點
- **大戶 Lead 規模**：公司人數 101~500 人，屬於中大型 B2B Enterprise 客群，極具指標性。
- **特定業務情境**：消費者於網站加入特定服務時，需要勾選或線上同意合約條款，此條款需 100% 符合《電子簽章法》效力，防範未來爭議。
- **技術串接需求**：尋求輕量級、高度合規之 API 介接與報價。
- **對接窗口**：已分配給好好簽產品顧問 **Kelly** 專人跟進。

## 詳細內容

### 1. 商業與場景解析
神坊資訊的需求屬於「聲明同意型 API (Consent API)」或「靜態條款電子簽署」。
這類場景的特徵是：
- **高頻、自動化**：由系統在使用者觸發特定動作（如加入會員、訂閱服務）時自動調用。
- **合法合規性大於簽名形狀**：用戶不一定需要親筆手寫，但系統必須產生符合《電子簽章法》規定的 PKI 加密數位簽章與時間戳記，確保自證力與抗否認性（Non-repudiation）。
- **商機規模**：若神坊資訊在其承接的國泰集團專案或自有雲端服務平台中全面導入，其年度合約份數與 API 調用量將非常龐大，具備極高客單價潛力。

### 2. 戰術建議與下一步工作
- **強調數發部能量登錄公信力**：在與神坊資訊洽談時，應重點強調好好簽**已成功通過國家數位發展部【電子簽章解決方案服務能量登錄】**，此為政府公信力背書之最安心通行證。
- **提供 Consent API 專屬說明書**：準備好針對網站服務條款同意（勾選即簽署/點擊即簽署）的輕量級 SDK 或 API 範例，向其開發團隊證明好好簽 API 具備零阻力整合優勢。
- **客製化企業方案 (Enterprise) 報價**：根據預估的月均/年均同意份數，提供量大更划算的 AATL 憑證階梯式報價，包抄競品。
