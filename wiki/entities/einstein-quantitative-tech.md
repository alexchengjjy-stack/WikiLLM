# 愛因斯坦量化科技股份有限公司

> 愛因斯坦量化科技（亦稱愛因斯坦量化智能科技）是一家專注於金融培訓與線上/實體教學課程的創新公司。規模為 1~10 人。於 2026 年 5 月主動諮詢好好簽，尋求能實現購課後自動帶入資料、並直接透過 LINE 傳送給客戶完成手機簽署的自動化系統串接。

## 核心要點
- **客戶場景**：線上銷售金融培訓課程，包含部分線下實體服務。
- **痛點需求**：
  1. 顧客線上購買後，後台系統需自動收到通知。
  2. 系統透過 API 串接好好簽，將購課個資與合約內容自動帶入範本中。
  3. 客戶直接用手機打開 **LINE**，即可在親切的行動介面上完成手寫簽名，免下載 App。
  4. 多數個人資料在首次填寫後，系統能記錄並自動帶入，無需重複手打。
- **核心優勢對接**：此需求完美契合好好簽相較於 DocuSign 等大廠的殺手級優勢 ── **LINE 官方帳號傳簽與高自適性輕量 API 範本填寫**。
- **分配與狀態**：已分配給好好簽產品顧問 **Kelly** 專人對接。

## 詳細內容

### 1. 商業與場景解析
愛因斯坦量化科技的場景是典型的 **PLG 漏斗與 SLG API 的合流點**：
- **高黏性與自動化需求**：金融培訓與高客單價課程在法規上需要完備的簽約，以防止退費糾紛或債權爭議。而「手動催簽」會耗費極高的人力，因此「API 自動化帶入資料 + LINE 即時完簽」是打破業務瓶頸的唯一解法。
- **LINE 傳簽的絕對統治力**：台灣消費者（特別是購買培訓課程的大眾）對 Email 的讀取率非常低，而 LINE 是每個人每天必用的工具。透過 LINE 傳簽，完簽率高達 95% 以上，成交速度能提升數倍。
- **防重複輸入的結構化資料**：利用好好簽的 API 範本帶入 (Template Fill API)，能讓前端網頁購買資料直接對應至 PDF 的特定 Fields，這對小型團隊 (1~10人) 的自動化維運極為重要。

### 2. 戰術建議與下一步工作
- **示範「一鍵 LINE 完簽」的 Demo 流程**：顧問 Kelly 應直接發送一封 LINE 測試合約給愛因斯坦承辦人，讓其親自體驗在手機 LINE 介面中 30 秒手寫簽名並自動上傳的極致流程，這通常是贏得合約的關鍵關鍵點。
- **提供 Template Fill API 文件與範例**：提供現成的 Python 或 Node.js 範例代碼，展示如何將線上購課後台的 Webhook 資料傳送至好好簽 API，完成合約自動生成。
- **定位為「高效率課程簽署首選」**：以「吃到飽方案」或「超高 C/P 值企業方案」對抗點點簽的高昂按份計費，說明我們不限份數的優勢最適合隨著他們招生規模擴大而無負擔擴展。
