# 福安管理顧問企業社

> 福安管理顧問企業社是一家提供工商顧問服務與健康管理諮詢的專業機構，資本額 300 萬元，員工人數約 40 人。該公司是好好簽（BreezySign）在 2026 年中旬成功攔截自點點簽（DottedSign）的指標性超大型客戶。

## 核心要點
- **超高簽署量需求**：每年約有 20,000 份的簽署需求，每月簽署量介於 2,000 到 4,000 份之間。
- **簽署場景與對象**：
  * 外部文件：健康管理服務記錄表文件、年度計劃記錄報告。對象為合作之事業單位與個人。
  * 內部文件：各縣市員工之簽呈與公文公告。使用人數達 60 位同事（每人每天簽署 2-3 份，單日最高達 180 份）。
- **轉單決策與時程**：
  * 原點點簽合約於 2026/6/30 到期。因點點簽改採以份計費後報價過高，促使福安尋求跳槽。
  * **SaaS 公版選用**：原先評估過 API 串接，但由於 IPO 對接時程來不及，福安決定今年直接採用 **好好簽 SaaS 公版**，預計選用企業版 60人方案（年費 NT$76,000）。
- **嚴格合規與輔導要求**：
  * **電子簽章法合規**：客戶強烈要求電子簽章服務需具備完整的法律合規佐證。我方已提供 ISO27001 認證與數位發展部「電子簽章服務能量登錄」核可文件。
  * **教育訓練**：客戶希望安排教育訓練並錄影供內部同事參考。目前雙方正在協調工作日（週二至週四）的培訓時程。
- **6/8 最新動態（55 人報價/政府補助）**：
  * 初期先使用 SaaS 方案，明年才考慮 API 串接；需求已升為 **55 人方案**報價。
  * 因需要申請**政府補助**，客戶要求提供合約文件與電子簽章解決方案服務能量登錄許可證明。
  * 已轉由 Jack 負責接洽。
