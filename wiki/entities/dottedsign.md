# 點點簽 (DottedSign)

> 點點簽是台灣老牌 SaaS 獨角獸 KDAN 凱鈿行動科技旗下的旗艦級電子簽章產品。其兼具本土服務的靈活與國際一線軟體的合規水準。

## 關鍵特色與定位

依據我們的[國內電子簽章服務競品比較](../analyses/domestic-e-signature-comparison.md)，點點簽的優勢主要集中在「中大團隊的成本效益」與「國際化軟體串接」：

1. **破壞性的計價優勢**：在國際與本土多數廠商採「人頭（per user）」計費時，點點簽商務版主打「任務包（100份/年）」，但**團隊人數無上限**。對於偶爾需要簽署的跨部門大團隊，能省下極其可觀的軟體授權費。
2. **頂尖的第三方平台整合**：與跨國軟體服務如 Google Workspace、Microsoft Teams 以及自動化工具 Zapier 擁有開箱即用的深度串接。
3. **API 取用友善**：許多其他品牌的 API 功能鎖在最頂級客製化方案內，點點簽在商務版（USD 200/年起）中即包含 API 可用性。
4. **國際市場體質**：系統為多語系、USD 美金計價，適合有跨國業務需求的企業採購。
5. **官方能量登錄**：已取得數發部「[電子簽章解決方案服務能量登錄](../sources/moda-esignature-energy-registration.md)」(113電簽0003)。

## 定價策略與抗性

在實務商戰中，點點簽雖然對中小企業團隊極具吸引力，但對於**大量簽署 (High Volume)** 的客戶，其「合約數計費」與改採「以份計費」模式將造成巨大的成本壓力與續約跳槽抗性：

- **大量簽署流失案例**：[福安管理顧問企業社](../sources/bzs-weekly-report-20260522.md)（2026/05），每年需求高達 2 萬份簽署量。目前點點簽合約於 6/30 到期，因點點簽改以份計費之報價過高，促使客戶主動評估並尋求好好簽企業方案（50人 $68k / 60人 $76k）替代。
- **漲價與卡頓流失案例**：多家中小型客戶（如麻吉行得通、聖美麗、富友旅行社）均在 2026 年中因點點簽變更計費模式引發漲價而尋求跳槽。
  - **[太平洋旅行社股份有限公司](../sources/bzs-weekly-report-20260522.md)**（2026/05）：原 40 人版年約 2000 份報價 7 萬多，已於 5/21 確定改採好好簽企業方案吃到飽（年租 NT$60,000），並啟用 UNIFY 範本分享功能，合約自 6/1 起算。
  - **台中浸信會**（2026/05）：原點點簽用戶，因其價格調漲且系統在使用中常卡頓，已規劃明年度預算，預計於明年 3 月正式導入好好簽專業方案。
  - **麻吉行得通**（2026/05）：點點簽 8/3 到期，改以份計費 500~600 份年約需 25,000 元，正積極評估好好簽企業方案。
