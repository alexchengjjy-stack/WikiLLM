# 好好簽 (BreezySign)

> 好好簽是台灣本土的電子簽章提供商，主打高度的台灣在地化整合以及親民的簽署體驗。

## 關鍵特色與定位

參考[國內電子簽章服務競品比較](../analyses/domestic-e-signature-comparison.md)中的分析，好好簽的獨家優勢在於：

1. **聲明錄影功能**：這是在目前台灣電子簽章軟體中相對罕見的功能，可以於簽名當下錄影證明，大幅提升具有高度紛爭可能合約的法律證據力。
2. **硬體緊密結合**：與蒙恬簽名板原生支援，非常適合金融業、實體門市的臨櫃簽署。
3. **通訊軟體在地化**：可以直接透過 LINE 寄發簽署邀請，比傳統 Email 更能觸及不會使用信箱或收信率低的長輩/終端消費者。
4. **文化適應**：有特別實作印章儲存的機制，符合台資企業或華人傳統的用印習慣。
5. **官方能量登錄**：已取得數發部「[電子簽章解決方案服務能量登錄](../sources/moda-esignature-energy-registration.md)」(113電簽0008)，具備政府標案與大型企業採購的信任背書。

## 定價與 API 授權策略
除了標準的訂閱制（按人頭計費），好好簽的企業授權與 API 模式極具彈性：
- **API 平台費**：可依專案預算調整，標準年費報價落在 $1.5 萬起至 $15 萬之間。
- **AATL 數位簽章計費**：AATL 憑證每份批價約介於 NT$20 ~ $30 之間（依購買量級距浮動），相較競品更具成本競爭力。
- **簡訊 OTP 費用**：約為 $2/則。
- **詳細標準定價**：參考 [好好簽價格方案](../sources/breezysign-pricing.md)、[2026 銷售日報分析](../sources/bzs-sales-reports-2026.md)。

## 生態系夥伴與主要應用客群
好好簽避免依賴單一通道， активно 開展 ISV 與代理商生態：
1. **醫療與生技**：與「方鼎」、「得勝者」等醫療資訊系統 (HIS) 廠商深度綁定，提供診所同意書結合「地端 NAS 資安備份」的混合解決方案，並推廣至醫美、安養中心與獸醫院。
2. **大型 ERP/BPM 整合**：與「鼎新電腦」(雲市集與 AI 諸葛平台) 以及「百加資通 101Form」等企業軟體結盟，採行 70% (好好簽) / 30% (整合商) 的分潤模式快速鋪貨。
3. **企業在地需求**：正在朝向支援 Docker 容器化地端部署與 SSO 單一登入發展，以對應更嚴苛的跨國公司或高資料敏感單位的採購規格。
