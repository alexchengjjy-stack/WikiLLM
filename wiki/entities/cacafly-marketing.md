# 聖洋科技股份有限公司 (cacafly)

> 聖洋科技 (cacafly) 是台灣知名的廣告顧問與數位行銷服務集團。公司規模達 101~500 人。於 2026 年 5 月底主動諮詢好好簽 (BreezySign)，尋求年用量高達 **8,000~10,000 份** 的合約 **API 串接** 方案。此客戶代表好好簽極具指標性與高利潤貢獻的 SLG (銷售驅動) 大量簽署大戶。

## 核心要點
- **客戶規模與產業**：101~500 人，廣告顧問、數位行銷服務業。
- **簽署合約用量**：一年預計 **8,000 ~ 10,000 份**。
- **痛點與具體需求**：
  1. 需要高穩定度的 **API 串接** 方案，將合約簽署無縫整合至其內部的商務流程或客資系統。
  2. **多品牌/子公司管理 (Multi-branding/Tenant branding)**：作為集團企業，旗下擁有多家不同子公司。要求系統在生成合約範本時，能夠**自訂帶出不同的公司名稱與公司識別 (Logo/視覺色調等)**。
- **分配與狀態**：已交由好好簽專屬商務顧問 **Kelly** 專人跟進，目前處於 Planning 與 API 技術方案對接階段。

---

## 詳細內容

### 1. 商業價值與多品牌 (Multi-branding) 需求解析
聖洋科技是一家非常典型的 **高價值企業級 (Enterprise) 客戶**，其合約用量大、客單價高，能為好好簽貢獻強勁的 ARR 增長：
- **集團子公司的識別隔離**：對於大型廣告/代理商集團，旗下通常設有數個獨立子公司分別簽約。如果電子簽章平台只能強制綁定一個母公司名稱與 Logo，會造成法律責任混淆與消費者體驗的不一致。因此，能靈活自訂「發起單位的公司名稱與品牌識別」是 cacafly 選型的關鍵關鍵點。
- **API 批量處理之必然性**：年需求量達 8,000 份以上（平均每月約 700~800 份）時，手動發起合約已經極不切合實際。好好簽必須提供高併發、極速完簽並包含 AATL 憑證保護的 API 架構支援。

### 2. 戰術包抄與截擊策略
- **守護財務毛利安全防線**：
  - *成本精算*：以平均每份合約變動成本 NT$1.68（AATL NT$1.5 + 15% 簡訊率）計算，10,000 份合約的直接變動成本達 NT$16,800。
  - *定價拒絕硬吞*：聖洋科技**絕不能直接套用年約 NT$15,000 的 5 人企業版吃到飽方案**，否則好好簽將虧損 NT$1,800，且極度消耗伺服器負載。
  - *大戶防線報價*：對標 Kelly 的大戶防線，銷售團隊應提供「企業商務 API 方案」或客製化大額年約。如年約 **NT$60,000 ~ NT$80,000** 不限件數，或基本費 NT$30,000/年 + 超額 AATL 憑證每份 NT$2.0~2.5 計收。這既能保持對點點簽以份計費（點點簽 10,000 份收費預估達數十萬）的巨大性價比優勢，又能為我方守住 **50% 以上的高毛利**。
- **展示 API 自動化 Sandbox 與 Logo 自訂功能**：
  - 開發團隊正落實 API 測試沙盒的自動化部署。應邀請 cacafly 團隊（Paul Lin）加入測試，並向其展示好好簽的「範本自訂 Fields 與品牌動態帶出」技術規格，以技術領先性贏得採購合約。
