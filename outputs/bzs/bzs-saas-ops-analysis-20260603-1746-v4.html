五、BZS 訂單、認列與對帳機制

SaaS 的營運指標主要區分為「財務金流實收 (Recurring)」與「合約訂單額 (Booking)」兩種認列時間與口徑： 1. 財務會計實收認列 (Realized Revenue)： - 以當月金流「實際扣款/電匯入帳」為基準。5 月總實收 NT$ 385,602（SaaS 實收 NT$ 104,480 + 專案實收 NT$ 281,122）。 - 此數據為 5 月份最精準之財務 Production 基準。 2. 合約訂單認列 (Booking)： - 以合約確認或開通生效日為基準。例如 太平洋旅行社 40 人企業年租約（NT$ 60,000），雖於 5/26 電匯入帳（認列於 5 月財務實收中），但合約生效日自 6/1 起算，業務面列入 6 月生效業績。 3. 對帳落差對齊： - 後台金流與 CSM 登記數據達成 NT$ 0 落差對齊（新購 NT$ 73,200 + 續訂 NT$ 10,880 = 實收 NT$ 84,080），對帳機制已步入規範化軌道。 4. 專案認列拆分： - 本月專案與 API 實收 NT$ 281,122 佔總營收 72.9%，此類屬於一次性（One-time）的系統整合費用，應與 SaaS 經常性訂閱收入（Recurring Revenue）進行物理拆分核算，以精準反映 SaaS MRR/ARR 的健康度。

  • 價值維度 (Value)：2026上半年實收已完全收回獲客成本（Payback Period < 12 個月）。以年流失率 5% 估算，客戶終身價值 (LTV) 達 NT$ 120,000。

2. SaaS 核心指標名詞解釋與業界基準

為使營運數據評估具備一致性，以下定義好好簽 (BZS) 指標基準（匯率以 1 USD = 32 NTD 計算）： - CPA / CPL (每次獲取/名單成本)：特指獲取單個註冊試用或高意圖諮詢 Leads 的廣告花費。 - 台灣 B2B 基準：NT$ 1,000 - 3,200 | 全球基準：NT$ 2,500 - 6,400+ - 好好簽實績：寬口徑 (含個人註冊) 為 NT$ 465，窄口徑 (僅企業 Leads) 為 NT$ 1,792（落在台灣正常均值內，成效極佳）。 - LTV : CAC (獲客效率比值)：衡量獲客投資回報率的黃金指標（健康標準 > 3 倍）。 - 好好簽實績：寬口徑為 258 倍，窄口徑 (B2B 決策基準) 為 67 倍（遠超業界標準，利潤空間極大）。

十、BreezySign 2026 行銷與營運策略全局綜合摘要 (H2 策略)

基於上述對帳、漏斗與競品普查，我們定調下半年四大戰略： 1. 建立財務與 CSM 數據月度對帳 SOP：每月 5 號前完成勾稽，標記扣款失敗與電匯差，控制誤差在 5% 內。 2. 優化 PLG (Product-Led Growth) Onboarding 引導：針對註冊後 50%~60% 從未簽署的 Cold Start 用戶，導入 3 分鐘引導動畫與範本，針對註冊 48 小時無動作 Leads 自動觸發 Email 並由 CSM 進行電訪關懷。 3. 擴大點點簽轉單定向行銷：放開 Google Ads 預算天花板，以「年約吃到飽、不限件數」為核心，定向投放點點簽漲價受災行業（如旅行社、連鎖醫療、人資派遣），攔截潛在 Leads，再由 CSM 迅速 Onboarding 轉換。 4. 中台化與通路嵌入：推動 API 與無程式碼元件，嵌入百加資通等 BPM 通路，加速 H2 規模化擴張。
