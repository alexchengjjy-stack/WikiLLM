🔥 凱鈿點點簽 (DottedSign) 漲價效應分析
點點簽近期更動計價模型，由原本的吃到飽租約改為以件計費（單份約 NT$45~50），這導致中大型簽署用量客戶面臨數倍的續約報價。

⚠️ 聖美麗健康文件大檔案憑證限制婉拒結案
醫療連鎖聖美麗（St. Mary）因其健康檢查文件多為富含影像的超大 PDF（單檔常超過 10MB），好好簽考量現行架構在嵌入 AATL 數位憑證時易因伺服器負載與超時失敗，若勉強承接將導致售後服務成本極大化。
【決策回報】：CSM 與技術團隊於本月正式予以婉拒年約，客戶選擇於 8/1 續約點點簽。此為我方首次針對「單檔 10MB 限額與 AATL 效能」主動退守之邊界，已記錄至系統規範中。

三、 好好簽 (BZS) 企業客戶畫像分析 (Customer Personas)

基於 2026 年度超過 60 份業務日報萃取，好好簽企業客群展現強烈的「產業垂直性」與「需求異質性」：

🏥 1. 醫療院所與生技保健

代表：得勝者(盧森眼科)、衡星牙醫、膚適美仁愛診所。
• 特徵：要求 HIS/PACS 系統 API 座標完簽與 PDF 自動轉 Dicom 回寫。
• 合規需求：偏鄉或斷線需部署輕量地端中繼程式，提供離線暫存與 NTP 3 天內校時上傳。
• 通訊：病患要求以 LINE/簡訊傳簽，並因資安稽核極重視「聲明錄影簽」與中華電信時間戳記。

🔥 2. 點點簽大漲價轉單大戶

代表：太平洋旅行社(40人吃到飽)、福安管顧(年簽2萬份)、海沃管顧。
• 特徵：點點簽改按件計費(每份$45~50)令中大型客戶成本翻倍，看重好好簽「吃到飽年租方案」。
• 內控需求：中大團隊要求 UNIFY 範本權限集中控制(子帳號禁止自建與修改範本)。
• 背書：高度要求數發部能量登錄核可與 ISO 27001 背書。

🏢 3. 不動產租售與代銷

代表：第一建經、佶星廣告、二房東星鴻。
• 特徵：業務親訪看房需平板現場簽。對法律證據力要求極高，要求「邊簽名邊錄影」與 AATL 數位憑證以自證法律效力。
• 編輯：習慣 Word 編輯，對線上 Word 預覽/編輯有潛在需求。

🏫 4. 大型教育與補教機構

代表：智基科技 (志光公職)。
• 特徵：年簽約量高達 3~5 萬份，決策鏈與導入期長，要求精確的階梯式報價 (Tiered Pricing)。
• 流程：結合「公開表單簽」(單一傳簽連結自主填個資)以降低業務手動 1 對 1 發送的行政成本。

💻 5. 企業內部 BPM 與地端部署

代表：台北 101 BPM 系統建置。
• 特徵：對 API 整合與網路安全要求極高。
• 私有雲需求：大型企業基於內部資安與合規，要求 Docker 地端部署、提供原始代碼安裝包，並討論 isHealth API 健全檢測。

🛡️ 6. 大檔案憑證限制防禦邊界 (婉拒)

代表：聖美麗健康管理顧問。
• 特徵：健檢報告多圖且 PDF 大於 10MB。大檔案在嵌入 AATL 數位憑證時易因伺服器負載超時而簽署失敗。
• 婉拒決策：我方評估修改系統架構耗費過大，主動予以婉拒年約，確立「單檔 10MB 與 AATL」防守防線，以保護服務毛利。

🔍 5月份 CPA 數據計算公式與定位分析 (當月 Google Ads 廣告費實算為 NT$ 145,080)
1. 寬口徑 CPA (NT$ 465)：NT$ 145,080 (花費) / 312 家 (當月新增總註冊) = NT$ 465 (用於評估大盤註冊引流效率，顯著低於台灣均值)。
2. 窄口徑 CPA (NT$ 1,792)：NT$ 145,080 (花費) / 81 次 (當月高意圖企業體驗申請與專人聯絡) = NT$ 1,792 (反映實質開發 SQL 之 CPL 成本，精確落在台灣正常均值 NT$ 300 ~ 1,500 區間中上游)。
3. 定位啟示：雖然窄口徑 CPA 受點點簽漲價轉單潮導致競字變貴而略升，但由於好好簽 B2B 企業 LTV 高達 NT$ 120,000，使 **LTV:CAC 仍達驚人的 67 倍**，財務結構極度健康，下半年應持續加碼 Ads 競品攔截投放。
