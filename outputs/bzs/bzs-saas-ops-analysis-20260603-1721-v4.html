BreezySign 好好簽 2026年5月營運月報

報告摘要：本月報彙整 2026 年 5 月份 BreezySign（好好簽）之營運財務、SaaS 訂閱與退訂狀況、重點企業專案與 API 對接進度、競品市場動態（以點點簽漲價轉單為主），並提出後續執行與產品建議。5 月份受惠於專案款項入帳與點點簽轉單效應，總實收營收達到 NT$ 385,602，展現 SaaS 訂閱與系統整合（SI/API）雙引擎增長。

一、營運進展

5 月份實收營收總計為 NT$ 385,602（金流認列口徑）。

1. 5 月份訂閱狀況 (SaaS Subscription)

本月訂閱各方案與加購項目明細如下： - 企業方案：NT$ 73,500 - 商務方案：NT$ 15,000 - 專業方案：NT$ 28,800 - 簡訊點數：NT$ 600 - 雲端憑證：NT$ 80 - 簽名板：NT$ 0 - 5月份訂閱小計：NT$ 104,480

2. 5 月份專案與 API 實收 (SI/API Revenue)

本月線下專案與 API 介接費用實收小計為 NT$ 281,122，各客戶明細如下： - 唯心醫院管理顧問：NT$ 61,425 - 百加-偉勝乾燥：NT$ 60,000 - NX：NT$ 52,500 - 百加-巨虹：NT$ 38,225 - 得勝者-盧森眼科：NT$ 25,000 - 得勝者-東港盧森：NT$ 25,000 - 瑋勝：NT$ 15,000 - 天元 寵物美容 POS：NT$ 2,640 - 合信數位：NT$ 1,332 - 專案實收小計：NT$ 281,122

二、SaaS客戶進展

5 月份 SaaS 經常性實收金流總計為 NT$ 104,480（包含當月扣款成功之新購與續訂名單）。

  • 簽名板：NT$ 0

三、SaaS 訂閱戶數據統計

根據後台營運數據與客成 (CSM) 統計： 1. 新增註冊公司數：本月新註冊公司達 312 家。 - 免費方案註冊：200+ 家 - 體驗方案（專業/企業體驗版）開通：70 家（包含 SaaS 體驗 7 家，API/SI 通路體驗 12 家等）。 2. 當月新購付費轉化： - 本月新簽訂閱共 9 家（包含 6 家專業方案，3 家企業方案），新購業績 (New Booking) 為 NT$ 13,200。 - 其中包含 CSM 團隊主動 Onboarding 轉化之典型客戶： - 豐盛富足資產管理（主動電訪教學範本，5/7 訂閱企業月約） - 自強工業科學基金會（安排線上 Demo 組織管理，5/15 訂閱企業版 2 個月） - 富友旅行社（針對旅遊代收轉付優化傳簽，5/8 訂閱專業方案年約）

四、SaaS 退訂戶數據統計

本月重點流失或主動婉拒續約/結案之客戶歷程如下： 1. 聖美麗健康管理顧問有限公司 (主動婉拒續約)： - 流失原因：客戶護理師上傳之 PDF 檔案（健檢大圖）多在 27~28MB。因超大檔案在嵌入 AATL 數位憑證時易造成伺服器負載超時、簽署失敗。評估調整系統架構將破壞毛利，因此 CSM 與技術團隊予以主動婉拒續約。本案已正式結案。 2. 行天宮醫療財團法人恩主公醫院 (臨櫃現場簽署專案結案)： - 結案原因：5 月初評估設置電子簽名平台供院內民眾現場簽署。5/20 院方來信表示，因今年院內資源與預算配置已滿，無法支援此案開發，本案正式結案聯絡。

五、BZS 訂單、認列

SaaS 的營運指標主要區分為「財務金流實收 (Recurring)」與「合約訂單額 (Booking)」兩種認列時間與口徑： 1. 財務會計實收認列 (Realized Revenue)： - 以當月金流「實際扣款/電匯入帳」為基準。5 月總實收 NT$ 385,602（SaaS 實收 NT$ 104,480 + 專案實收 NT$ 281,122）。 - 此數據為 5 月份最精準之財務 Production 基準。 2. 合約訂單認列 (Booking)： - 以合約確認或開通生效日為基準。例如 太平洋旅行社 40 人企業年租約（NT$ 60,000），雖於 5/26 電匯入帳（認列於 5 月財務實收中），但合約生效日自 6/1 起算，業務面列入 6 月生效業績。 3. 專案認列拆分： - 本月專案與 API 實收 NT$ 281,122 佔總營收 72.9%，此類屬於一次性（One-time）的系統整合費用，應與 SaaS 經常性訂閱收入（Recurring Revenue）進行物理拆分核算，以精準反映 SaaS MRR/ARR 的健康度。

六、重點專案進展

1. 通路合作與技術對接 (Channel & Technical Integrations)

  • 鼎新電腦 (ISV 戰略合作)：API 串接已全數完成。本月針對 AI 拋出連結在 GCP 載入慢的問題進行技術調優，已成功將連結有效時間由 60 秒調增為 15 分鐘，大幅降低用戶操作摩擦。目前處於合約最後審核階段，並全力備戰 6/11 的聯名直播行銷活動。
  • 百加資通 (BPM 通路合作)：本月配合 偉勝乾燥 專案實收 NT$ 60,000，已於 5/30 開立發票；巨虹電子 專案實收 NT$ 38,225。凌越生醫 專案，因其主管不願再採購另一套 BPM 系統，且其需求可直接由百加的 101 Form 滿足，我方已婉拒客製需求，本案已結案。
  • 得勝者 (醫療 HIS / PACS 系統整合)：旗下 盧森眼科 與 東港盧森 專案時程已確立，預計 6 月進行測試、7 月正式上線，每家收費 NT$ 25,000（含 1,500 份 AATL 憑證，兩案共計 NT$ 50,000 實收，已於 5 月專案款項中認列）。6/1 早上與得勝者團隊召開年度整體規劃會議，並與南港「商之器」洽談其 PACS 後台 AI 醫療影像平台 mAIn 之後台 AI 引擎電簽 API 整合。規避斷線合規的「地端離線暫存與中華電信 NTP 校時機制」已設計。
  • 中華電信 (憑證與時戳合規)：為 API 介接廠商 瑞飛智慧 釐清好好簽的 AATL 憑證確實是由中華電信 CA 提供的合規澄清。好好簽全面對齊「中華電信 AATL 憑證與 LTV 完整時戳」，作為符合電子簽章法第 6 條推定法律效力之信任錨點。
  • 台北 101 (地端 BPM 建置獨立專案)：台北 101 BPM 專案為好好簽之獨立大型地端部署專案（非中華電信引薦）。目前已交付地端原始碼與 Hi-Cloud / DMZ 安裝文件，支援 10 份雲端憑證，正進行異常通知 isHealth API 檢測機制討論。

  • 大瀚 GTB (共享辦公租客訂閱合作案)：專屬合作測試版 Landing Page 已確認無誤，預計於 6 月初正式上線，好好簽將提供大瀚租客專屬之「免費 3 個月測試」體驗。本專案旨在透過大瀚商務中心之生態合作，獲取其旗下大量企業租客的付費訂閱，開拓新型態 of B2B2C 增長模型。

  • 聖洋科技 (cacafly) API 串接：預估年用量 8,000 ~ 10,000 份，正進行多品牌動態 Logo 規格規劃，我方初步報價每份 NT$ 20。
  • 神坊資訊 (小樹購 API)：預計年用量 2,000 份，正評估導入 API，嫌年費高已說明可談，我方正提供金融業合作實績中。

  • 麻吉行得通 (點點簽轉單)：500 ~ 600 份年約轉單跟進，積極對接 8/3 到期轉換好好簽之決策。

七、競品概況

5 月份電子簽章市場中，主要競爭對手 點點簽 (DottedSign) 流失用戶的轉單潮持續發酵： 1. 計費模式變更引發反彈：點點簽改為「以件計費/按份計費」並大幅漲價（每份約 NT$ 45~50，如 1,300 份文件年費高達 NT$ 58,500）。這對中高頻簽署之企業客戶（如太平洋旅行社 2,000 份、福安 2 萬份、白雪公主旅行社 1,000 份等）造成沉重費用負擔。 2. 效能卡頓與客服延遲：部分轉單客戶反饋點點簽在行動裝置上發起與簽署卡頓，且客服回覆效率低（常需等待一週）。 3. 好好簽的競爭優勢：好好簽以「吃到飽年約定價（如企業方案年費 NT$ 15,000 不限件數）」為核心優勢，成功吸引上述大戶轉單。本月 太平洋旅行社 已正式電匯付款 NT$ 60,000 訂閱 40 人企業方案年租，合約於 6/1 生效。

八、BreezySign 後續執行、建議

  1. 建立月度財務與 CSM 數據對帳 SOP：
  2. 每月 5 號前，以財務實收金流為基準，勾稽 CSM 系統記錄之新購與續約名單。標記自動扣款失敗與線下電匯開通之時間差，將口徑誤差控制在 5% 以內。
  3. 優化 PLG (Product-Led Growth) 產品 onboarding 流程：
  4. 鑑於 50%~60% 的註冊用戶在註冊後「從未簽署（Never signing）」，應於產品內導入「3 分鐘引導動畫」或「一鍵套用範本」引導。同時，系統應針對「註冊 48 小時內未簽署」之 Leads 自動觸發引導 Email，並由 CSM 團隊介入電訪關懷，打破冷啟動。
  5. 擴大點點簽轉單精勢行銷：
  6. 行銷與業務團隊應針對受點點簽以件計費影響之高頻簽署行業（如旅行社、連鎖醫療、人資派遣等）發起定向廣告，以「不限件數年約方案」為核心訴求，主動攔截潛在 Leads，再由 CSM 團隊迅速切入 Onboarding，複製太平洋旅行社的成功轉化軌跡。
