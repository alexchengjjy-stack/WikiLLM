## 📁 目錄規範

- **不加入 Git 追蹤**：建議在 `.gitignore` 中忽略本目錄下除 `README.md` 以外的所有檔案（若有 Git 管理）。
- **命名建議**：`YYYYMMDD-專案名-格式.ext` (例如：`20260515-esign-snapshot-v1.html`)。
- **定期清理**：本目錄檔案被視為「快照產物」，應在交付或展示後定期清理，以保持工作區輕量。
